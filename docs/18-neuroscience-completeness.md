## 1. 脑干层（生存、自主神经）

维持生命的基本功能。对应AureusBot的"生物学基础"。

### 脑干的生理功能

| 人脑结构 | 功能 | 对应参数 | AureusBot实现 | 状态 |
|--------|------|--------|--------|------|
| **脑干网状激活系统（RAS）** | 觉醒、警觉、过滤信息 | `arousal` | CircadianModel + UltradinRhythm | ✅ 完整 |
| **延髓（medulla）** | 呼吸、心跳、反射弧 | 隐含 | 心跳循环（Phase 0.6） | ⏳ 规划中 |
| **脑桥（pons）** | 睡眠-觉醒切换 | `sleep_debt`, `energy` | BiologicalState 的睡眠模型 | ✅ 框架就绪 |
| **中脑（midbrain）** | 多巴胺分泌、奖励处理 | `dopamine` | 激素触发器 | ✅ 完整 |

### 为什么这层很关键

- 脑干是整个大脑的**能量供应和控制中心**
- AureusBot的 BiologicalState + Circadian 模型完整实现了这一层
- 相当于AureusBot有了"生命体征"

## 7. 设计对比：为什么不要多 Planner？

### 多 Planner 并行的神经学问题

| 假设 | 实际情况 | 结论 |
|------|--------|------|
| "人脑能多进程工作" | ✓ 真（基底核、小脑、视觉皮层可并行） | ❌ 但前额皮质**必须**串行 |
| "所以规划也能并行" | ✗ 假（规划在背侧前额皮质，高度串行） | ❌ 会导致冲突 |
| "用锁和同步就行" | ✗ 假（那样就不是真正的并行了） | ❌ 徒增复杂性 |

### 真实的人脑"并行"

```
前额皮质（规划）    ▓▓▓▓▓▓▓▓  高度串行
                     ↓
       每次做一个决策
       决策由这些影响：
           ↙    ↓    ↘
    脑干    边缘系统   感官输入
   （并行） （并行）   （并行）
```

**关键**：多进程发生在**约束系统**（激素、能量、情绪），不是决策系统本身。

### D34 的优雅之处

```python
# 不是多 Planner
decision = await planner.decide(context)

# 而是多个约束系统实时影响单一 Planner
context.constraints = {
    "energy": bio.energy,           # 脑干贡献
    "risk_aversion": bio.risk_aversion(),  # 边缘系统贡献
    "social_boost": bio.social_motivation(),  # 社交脑贡献
    "meta_awareness": bio.observe_cognitive_state(),  # 元认知
}

# Planner 在这些约束下运行
decision = await planner.decide(context)

# 多 Planner 不需要，因为影响已经在约束中了
```

这就是**生物学的并行与认知的串行的完美结合**。
