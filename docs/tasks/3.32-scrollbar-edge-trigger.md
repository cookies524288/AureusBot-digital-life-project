# 3.32 滚动条只在指针靠近边缘时变粗

状态：待实现
设计：D133（docs/10-decisions.md）

## 先读

- `aureus/web/static/index.html`：全局滚动条 CSS（`::-webkit-scrollbar` 与悬停变粗规则）、`showPage`、`startPageEntrance`。

## 问题

现在的变粗规则是「悬停在可滚动区域任意位置」，切页后鼠标停在页面中间，滑块也保持变粗；指针根本没靠近滚动条。

## 目标和验收

1. 只有指针进入可滚动区域的右边缘（竖向滚动）或底部（横向滚动）约 24 像素内时，滑块才变粗；离开立即恢复。
2. 切页、滚动、窗口尺寸变化后状态正确重置；鼠标在页面中间时滑块保持细胶囊。
3. 变粗只改滑块视觉宽度，不改变布局；深浅主题正常。
4. 学习工作台内部（Shadow DOM）的滚动条同样适用，或至少不受主页面规则误伤。

## 改动一览

- `aureus/web/static/index.html`：滚动条 CSS 改为按边缘类名触发；新增指针监听（`pointermove`/`pointerleave`）与切页重置。

## 行为细则和边界情况

1. 判定用元素边界：`clientX >= rect.right - 24`（且 `clientY` 在元素内）或 `clientY >= rect.bottom - 24`（横向）。
2. 只对真正可滚动的元素（`scrollHeight > clientHeight` 或 `scrollWidth > clientWidth`）添加边缘类。
3. 同一时刻只保留一个元素的边缘类；指针离开文档时清空。
4. 学习工作台若在 Shadow DOM 内，主页面规则不生效时在宿主上补同样的监听或接受其原生样式，并在任务文档说明。
5. 不做：改变滚动条基础样式、改变滚动行为。
