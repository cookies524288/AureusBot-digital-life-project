# Phase 3.11 维护 · 网页分页与切页交互

状态：实现中

## 先读

[交接](../handoff.md)、[资源管理验收](resource-management.md)、[参考与迁移](../13-references-and-migration.md)、[开发守则](../11-dev-guide.md)。本轮是资源管理与网页交互维护，不替代 3.13 待评审和 3.14 QQ 表情发送的工作。

## 目标与验收

1. 切换页面时，依赖权限、选择或服务端状态的操作默认不可用；慢请求、失败与快速切换不得激活旧操作或覆盖新视图。
2. 学习和长期记忆按类别进入独立视图，使用分页而不是向下累积记录。表情和图片使用可切换大、中、小的缩略图矩阵；长正文、证据与原图按需查看。保留已有筛选、编辑、恢复、导入导出及旧入口。
3. 用公开 MaiBot 界面作为参照；用合成数据和浏览器验证桌面、窄屏、翻页边界和加载状态。极小窗口允许必要的滚动，不能为消灭滚动条而截掉可操作内容。

## 子步骤

公共导航审计、资源视图实现和独立行为验收并行；集成后进行质量复审和完整检查。只合并本轮分支，不合并历史或备份分支；清理已确认的测试临时文件，不操作正式数据和已有工作树。

## 不做

不改学习、召回或 QQ 发送策略，不读取个人 MaiBot 数据，不调用真实模型，不推送。

## 待设计问题

无。
