## 交付顺序和验证

1. 页骨架与已接操作保持可用；没有后端的子页另开交付，不把静态布局算作已实现。
2. 质检、图授权、事实/画像/关系维护、包成员拆开交付。每次同时核对操作页、写入与读取、真实回复候选、撤销/撤权，不以 HTTP 200 代替结果。
3. 按固定版对照补齐检修/调优、图片、包、表情维护和学习细节。公开许可允许的原代码注明文件头与 `THIRD_PARTY.md`；非兼容的实现按接口重写。维护者本机 MaiBot 数据库、日志、配置、聊天均不读取。

不做：从模板截图抄数据、让导入包替用户扩大授权、真实收费测试、物理清除正式数据以验证回收。
