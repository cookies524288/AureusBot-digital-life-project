# Windows 启动器

状态：完成（2026-11-22，正式评审通过）

## 目标和验收

- 双击项目根目录的 `Aureus.exe` 后，使用该目录已准备好的 uv 虚拟环境启动 Aureus，网页开始监听后打开默认浏览器，启动时无终端窗口。
- 本机浏览器登录并改掉默认密码后，侧栏可打开同一实例的交互终端。关闭终端窗口后网页继续运行，可再次打开终端；终端里的 `/quit` 正常关闭 Aureus。
- 原有 `aureus chat` 保留主动打开终端的行为。网页按钮仅在 Windows 启动器模式下对本机开放。
- 托盘左键打开网页，右键可正常退出程序。同一数据根目录的网页已启动时，再双击会打开它实际监听的地址。普通 `aureus chat` 启动的网页也可复用。
- 托盘右键菜单提供「打开主页面」，和左键点击复用同一地址。
- 网页侧栏确认「确定要关闭程序吗」后正常停机。取消或按 Esc 时保持运行。接口要求改过默认密码的登录会话以及同源发起。

## 范围

Windows 图形启动入口、现有终端通道的本机窗口和网页按钮。启动器使用现有数据根目录解析和单实例锁。隔离验收只用临时数据和假器官。

## 使用

2026-11-22 追加重启入口。CLI 使用 `/restart`，网页侧栏提供带确认的「重启」，托盘右键提供「重启」。重启先正常关闭心跳和网页，保留数据目录和启动模式。网页重启要求登录、修改默认密码并同源发起。维护者当时暂缓了全量检查。

在项目目录运行 `uv sync` 准备环境，并按 README 准备数据目录。双击根目录的 `Aureus.exe`，系统默认浏览器的普通标签页先显示启动状态，网页就绪后在同一个标签页进入主页面。启动失败时，状态页保留失败原因。如要重新构建，在 PowerShell 中运行 `./scripts/build-launcher.ps1`。旧启动器正在运行时，可以用 `-OutputPath` 将新版本构建到另一位置，等旧启动器退出后替换原文件。

双击启动时优先使用 `AUREUS_HOME`。需要为当前检出固定一个已有的数据根目录，可在 `Aureus.exe` 旁创建 UTF-8 文本 `aureus-home.txt`，只写该目录的绝对路径。未设置环境变量且没有该文件时，仍使用当前检出下的 `aureus_home/`。该文件由 Git 忽略，常规 `aureus chat` 沿用原有数据根目录规则。

重复打开同一数据目录时会复用已有服务。双击启动和托盘打开网页都使用 Windows 的默认打开方式。浏览器管理登录会话和标签页，退出 Aureus 后可手动关闭标签页。

离线试运行可以在 PowerShell 中执行 `./Aureus.exe --fake`。

如果升级前的实例仍在运行，先正常退出一次，再双击新版。新版在网页监听成功后发布实际端口，停机时撤销。同一数据根目录连续或同时启动时，只有拿到核心锁的进程启动服务。
