# Windows 启动器

状态：完成（2026-11-22，正式评审通过）

## 目标和验收

- 双击项目根目录的 `Aureus.exe` 后，使用该目录已准备好的 uv 虚拟环境启动 Aureus，网页开始监听后打开默认浏览器，启动时无终端窗口。
- 本机浏览器登录并改掉默认密码后，侧栏可打开同一实例的交互终端。关闭终端窗口后网页继续运行，可再次打开终端；终端里的 `/quit` 正常关闭 Aureus。
- 原有 `aureus chat` 保留主动打开终端的行为。网页按钮仅在 Windows 启动器模式下对本机开放。
- 托盘左键打开网页，右键可正常退出程序。同一数据根目录的网页已启动时，再双击会打开它实际监听的地址。普通 `aureus chat` 启动的网页也可复用。
- 托盘右键菜单提供「打开主页面」，和左键点击复用同一地址。
- 网页侧栏确认「确定要关闭程序吗」后正常停机。取消或按 Esc 时保持运行。接口要求改过默认密码的登录会话以及同源发起。

## 范围

Windows 图形启动入口、现有终端通道的本机窗口和网页按钮。启动器使用现有数据根目录解析和单实例锁。隔离验收只用临时数据和假器官。

## 使用

调试现有实例时，可在项目根目录运行 `./debug-restart.ps1`。它按启动器已有的 `AUREUS_HOME`、`aureus-home.txt`、默认数据目录顺序定位数据根目录，仅读取该目录当前公布的本机网页地址并打开系统默认浏览器；网页登录并改过默认密码后，在侧栏点击「重启」及确认。脚本本身不会发重启请求，也不读取登录令牌、密钥或用户数据，不会新建第二个实例。没有公布地址或浏览器无法打开时只报未完成，不猜测默认端口，也不声称已重启。Windows 以外的系统、没有发布网页地址的旧版实例不在该入口覆盖范围内。

在有交互终端的 Windows PowerShell 中运行 `./debug-restart.ps1 --restart` 可直接申请一次**正常重启**。非交互终端直接拒绝；输入 `yes` 后，在终端隐式输入已设置的网页登录密码，取消或 EOF 不发请求。程序不从参数、环境变量或磁盘取密码，不读取浏览器已有会话。它只连接所选数据目录发布的回环地址，登录前严格核对端口监听进程的路径、创建时间和 `Aureus.exe → 本项目 .venv/Scripts/pythonw.exe（含 --tray --owner-pid）→ 该虚拟环境对应的基础 Python 安装目录/pythonw.exe（实际监听）`。基础解释器路径仅从运行该脚本的项目虚拟环境严格推导；路径缺失或不可读取时拒绝认证，不按同名文件放行 直属链；不能证明此链就拒绝，不放宽为任意祖先进程。网页登录后再次核对身份及监听进程，使用同源接口只提交一次正常重启，不经代理或重定向。提示「已接受一次」只表示旧实例确认收到请求；等待阶段**不再发送密码或登录新进程**。只有稳定的原启动器、确认旧监听进程退出、不同且后启动的监听进程与无需登录的网页首页共同证实服务恢复，才报告「同一启动器下新监听进程接管、首页恢复」；没有核实新内核的网页会话身份，不能冒称已验证该项。旧进程仍监听、超时或结果不明均不重复请求、不启动第二实例。如需要手工确认，仍可不带参数运行脚本打开网页。此自动路径仅覆盖上述可证实的托盘启动链；其他启动方式退回网页人工确认，不代替正式实例的发布验收。

2026-11-22 追加重启入口。CLI 使用 `/restart`，网页侧栏提供带确认的「重启」，托盘右键提供「重启」。重启先正常关闭心跳和网页，保留数据目录和启动模式。网页重启要求登录、修改默认密码并同源发起。维护者当时暂缓了全量检查。

在项目目录运行 `uv sync` 准备环境，并按 README 准备数据目录。双击根目录的 `Aureus.exe`，系统默认浏览器的普通标签页先显示启动状态，网页就绪后在同一个标签页进入主页面。启动状态页通过回环 HTTP 地址打开，使用 Windows 的 HTTP 协议关联。启动失败时，已打开的状态页显示失败原因。如要重新构建，在 PowerShell 中运行 `./scripts/build-launcher.ps1`。旧启动器正在运行时，可以用 `-OutputPath` 将新版本构建到另一位置，等旧启动器退出后替换原文件。

双击启动时优先使用 `AUREUS_HOME`。需要为当前检出固定一个已有的数据根目录，可在 `Aureus.exe` 旁创建 UTF-8 文本 `aureus-home.txt`，只写该目录的绝对路径。未设置环境变量且没有该文件时，仍使用当前检出下的 `aureus_home/`。该文件由 Git 忽略，常规 `aureus chat` 沿用原有数据根目录规则。

重复打开同一数据目录时会复用已有服务。双击启动和托盘打开网页都使用 Windows 的默认打开方式。启动器确认这一实例已经退出后，其打开的标签页会尝试自动关闭。浏览器限制自动关闭时，页面显示「Aureus 已退出」，可以手动关闭。内核重启期间保留这些标签页。

2026-11-23 的已校验备用构建在 `E:/Temp/Aureus-3.13-tabs.exe`。待正式 Aureus 完全退出后，保留旧版备份，再将备用文件复制到项目根目录并命名为 `Aureus.exe`。也可以在项目根目录直接运行 `./scripts/build-launcher.ps1` 从已提交的源码重新构建。

离线试运行可以在 PowerShell 中执行 `./Aureus.exe --fake`。

如果升级前的实例仍在运行，先正常退出一次，再双击新版。新版在网页监听成功后发布实际端口，停机时撤销。同一数据根目录连续或同时启动时，只有拿到核心锁的进程启动服务。
