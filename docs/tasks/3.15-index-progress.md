# 3.15 · 嵌入器官的真实索引进度

状态：待评审。对应第 14 项。先读 `aureus/organs/llm_adapter.py` 的 `EmbeddingOrgan`、`core/model_runtime.py`、`heartbeat/{expression_recall,inbox_images,emoji_selection,conversation}.py`、`memory/expression_index.py` 与 `web/static/index.html` 的 `openOrganEditor`。

## 数据口径

- **本地表达**：`expression_runtime_vectors` 是持久索引。分子只计有效候选键、当前内容指纹及当前本地模型空间全部匹配的项；分母沿用表达候选的审核、移除、去重与适用范围。不得直接以向量表行数除以表达表行数。空间不匹配是待补建，功能关闭和没有候选分开显示。
- **图片**：`inbox_image_vectors` 是按收件消息及附件键保存的持久索引。按已保存的合格图片和实际模型空间计数；不可读会话、已清理附件不可借统计泄漏。切换图片模型时不将原空间向量算作新空间完成量。
- **通用文本**：长期记忆重排是按请求编码，无全库持久向量任务；表情描述走运行时缓存。若展示缓存覆盖，明确标为内存缓存、按实际空间与有效描述计数，不能写成记忆索引。没有适用索引时说明原因；未运行、没有模型或无法统计不要画作 100%。模型有候补路线时分别标实际空间，不泄露地址、密钥或原始资料。

## 子步骤与验收

1. 服务端从已装配的真实索引和模型读取只读计数；较重的 SQLite 读取在工作线程中执行，不触发建表、建索引、回填、模型探测或调用。索引空间的计算复用运行时规则，不用模型展示名称猜身份。计算前后空间变化时不把旧结果标成当前进度。
2. 在嵌入器官配置弹窗**左侧**显示像素分格进度条及确切的“已建立 / 可建立”文字；小屏改为上下排，不能挤掉模型编辑框。提供进度条的可访问名称和数值；弹窗关闭、切器官或切模型时丢弃迟到响应。未观察到真实后台作业时标成“部分已建立”，不用动画假装正在建。
3. 合成覆盖空库、功能关闭、部分建立、指纹失效、换空间、图片权限和迟到响应；打开弹窗不写库、不调用模型，不改变现有检索排名。按 D104 交付，纯计数不登记为新的认知状态。

- [x] 真实空间和有效候选：专项 `tests/web/test_index_progress.py` 覆盖表达审核、编辑指纹失效、移除、去重、包授权，图片权限和清理附件，以及表情缓存实际空间。图片候补按路线分列，老空间不计入新空间。
- [x] 只读边界：合成库测试核对认证、`no-store`、查询前后数据库文件一致；查询逻辑走独立只读连接，不续期、不发起模型调用或补建，表达候选和指纹使用同一数据库快照。运行时热切换测试覆盖读取途中换空间。
