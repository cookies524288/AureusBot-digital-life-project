# 3.46 平台会话头像与图片缓存

状态：待实现
设计：维护者 2026-11-26 指令；可参考 MaiBot 公开源码

## 目标

平台会话里的用户头像与图片重复进入会话时不再重复下载，提升切换与滚动性能。

## 实现

1. 前端：头像与图片按 `(平台, 发送者)` / 图片标识缓存为 object URL 或内存 Map，同一会话内复用；离开会话后可保留有限数量，按 LRU 清理。
2. 后端：头像与图片响应加合适的 `Cache-Control`（同源、私有、带 max-age），配合浏览器缓存；仍按权限校验，撤权后不再返回。
3. 不改权限与撤权语义；缓存按登录会话隔离，退出清空。
4. 与 3.41 的图片预览、3.43 的实时推送兼容。

## 验收

- 第二次进入同一会话头像/图片不再发请求或命中浏览器缓存；切换会话与滚动流畅；退出登录后缓存清空；撤权后旧缓存不被继续使用。
