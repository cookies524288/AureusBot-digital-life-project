# 3.46 平台会话头像与图片缓存

状态：待实现（前端待做）
设计：维护者 2026-11-26 指令；可参考 MaiBot 公开源码

## 目标

平台会话里的用户头像与图片重复进入会话时不再重复下载，提升切换与滚动性能。

## 实现

1. 前端：头像与图片按 `(平台, 发送者)` / 图片标识缓存为 object URL 或内存 Map，同一会话内复用；离开会话后可保留有限数量，按 LRU 清理。
2. 后端：头像与图片响应加合适的 `Cache-Control`（同源、私有、带 max-age），配合浏览器缓存；仍按权限校验，撤权后不再返回。
3. 不改权限与撤权语义；缓存按登录会话隔离，退出清空。
4. 与 3.41 的图片预览、3.43 的实时推送兼容。

## 后端部分已完成（2026-11-26）

- `aureus/web/inbox_api.py`：头像与图片的二进制响应统一返回
  `Cache-Control: private, max-age=30`（常量 `MEDIA_CACHE_SECONDS`），并保留
  `X-Content-Type-Options: nosniff` 与 `Cross-Origin-Resource-Policy: same-origin`；
  重复进入会话时由浏览器私有缓存直接命中。`view=description` 等动态 JSON 仍为 `no-store`。
- 权限校验不变：会话有效性与来源授权在读取前后都检查；未授权、撤权或不可读的 404
  统一带 `Cache-Control: no-store`，拒绝结果不会被缓存，重新授权后立即恢复。
- 撤权窗口：浏览器已缓存的旧响应最多在 `MEDIA_CACHE_SECONDS`（30 秒）内过期，
  过期后的下一次请求重新走权限校验；更长的复用由前端 object URL 缓存负责（待做）。
