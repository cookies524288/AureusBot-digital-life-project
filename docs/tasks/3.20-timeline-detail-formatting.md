# 3.20 时间线「详细信息」改成直观的中文信息

状态：待实现
设计：D124（docs/10-decisions.md）

## 先读

- `aureus/web/static/index.html`：时间线渲染 `renderRecord` / `renderTimeline` 与「详细信息」折叠区。
- `aureus/web/timeline_api.py`：`_timeline_item` 返回的 `metadata` 字段。
- `aureus/heartbeat/main_loop.py`、`aureus/heartbeat/planning.py`：状态变化、判断、回复参考等事件写入的 metadata 键。
- 隔离实例：数据根 `E:/Temp/aureus-ui-review`，端口 18770。

## 目标和验收

时间线每条记录的「详细信息」不再直接展示原始字段名、浮点数和 ISO 时间，而是转成用户能读懂的句子或键值行。

验收：

1. 状态变化：显示「当前任务、规划深度、规划把握、把握说明、情绪变化、精力、注意力、理由、阻碍、下一步、更新时间」等中文标签；时间用本地可读格式，不出现 ISO 字符串。
2. 情绪只列有变化的项，显示名称与变化方向/数值（如「愤怒 ↑0.08」）；0 值不显示；浮点最多两位小数。
3. 判断：显示判断到的情绪、触发的好感/激素变化（如有）、失败原因；不显示内部 id。
4. 回复参考：显示回复方向、长度、理由、工具名；不显示工具原始参数与内部编号。
5. 设定被改：显示改了哪一层、从什么改成什么（有旧值时）或「已更新」；不显示版本号以外的内部键。
6. 其它事件类型按同样原则映射；未知字段归入「其它」并尽量转成中文标签，实在无法解释的才隐藏。
7. 深浅主题、窄屏正常；「详细信息」默认折叠行为不变。

## 追加要求（2026-11-25）

时间线的筛选工具条（时间范围下拉 + 「全部 / 回复 / 规划 / 日记与人设 / 行动与日程 / 系统与安全」这一排）也移到页面底部（与滚动摘要一起），并且切换筛选时**不刷新页面、不重置用户滚动位置**：只更新列表内容，切换前后保持当前滚动位置（内容高度变化时按比例或锚点补回）。

## 改动一览

- `aureus/web/static/index.html`：详情渲染函数与键名/枚举映射表、数值与时间格式化。
- 必要时在 `aureus/web/timeline_api.py` 补充人类可读字段（如激素名称与增量）；不改变原始 metadata 的存储。

## 行为细则和边界情况

1. 映射表集中定义（键 → 中文标签、值格式化器），不要在每个事件类型里散落。
2. 激素名沿用术语表（anger 愤怒、joy 喜悦、hurt 难过、surprise 惊讶等）；未知激素名原样显示。
3. 数值：整数原样；浮点保留两位并去掉多余的 0；百分比类按现有语义显示；空值显示「—」。
4. 时间：本地时区、`11月25日 20:31` 格式；同一天只显示一次日期。
5. 原始字段不丢失：仍保留在 API 与数据库；前端只是不直接展示。确需排查时可通过现有接口查看。
6. 不做：修改时间线写入、改变事件类型、删除任何记录。
