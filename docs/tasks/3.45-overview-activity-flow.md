# 3.45 总览页「回复参考」改成最新一轮活动信息流

状态：待评审
设计：维护者 2026-11-26 指令；可参考平台会话的活动面板实现与 MaiBot 公开源码

## 目标

总览页的「回复参考」卡片改成与平台会话页同款的活动信息流，显示最新一轮的模型调用步骤，但保持总览页现有卡片与配色风格。

## 实现

1. `aureus/web/static/index.html`：总览页「回复参考」卡片内容替换为最新一轮的活动步骤（收到/判断/规划/回复参考/投递），只显示最新一轮。
2. 数据来源沿用 `/api/overview` 与时间线（可复用平台面板的轮次渲染函数，但样式用总览卡片体系）。
3. 无活动时显示待机状态；不新增后端字段，缺字段写「—」。
4. 不改变总览其它卡片与布局。

## 验收

- 总览页显示最新一轮活动步骤；无活动显示待机；与总览风格一致；窄屏与主题正常。

## 前端实测（2026-11-26）

实现：总览「回复参考」卡片改成 `ov-card-head` + `ov-activity-flow`，复用平台会话的
`inboxActivityLatestRound` / `inboxActivityRound` 计算并渲染最新一轮，样式用总览卡片
变量（`--tile-*`、`--signal`）覆盖；数据来自 `/api/timeline?hours=24&limit=60`，缓存键
`overview-round`，由 `timeline`/`round` 实时事件失效。没有新增后端字段。

- 最新一轮：在私聊页发一条网页消息后，总览卡片自动出现「轮次 #91」和收到消息、判断、
  规划、回复参考、投递五步；判断在本轮为「跳过」，规划里的行动与依据正常显示。截图
  `E:/Temp/ui-shots/343-03-overview-round.png`、`343-17-overview-round-dark.png`。
- 待机状态：没有近期轮次时卡片显示像素方块和「待机中」；初始总览截图
  `E:/Temp/ui-shots/343-00-overview.png`。
- 风格与窄屏：卡片沿用总览的九宫格底纹、`ov-card-head` 和「最新一轮」小字，步骤边框用
  `--tile-rule`/`--signal`，深浅主题正常；390×700 窄屏下卡片宽 312px、高 267px，
  5 步无横向溢出（`scrollWidth <= clientWidth`）。截图
  `E:/Temp/ui-shots/343-18-overview-round-narrow.png`、`343-19-overview-round-narrow-dark.png`。
- Console `exceptions=[]`、`errors=[]`；按维护者要求未跑 pytest。环境同 3.43：使用
  `E:/Temp/aureus-ui-review-343` 副本（端口 18780），原 18770 和正式 28976 未改动。
