# 3.35 时间线底部筛选标签切换时不跳到顶部

状态：完成
设计：维护者 2026-11-26 指令

## 问题

时间线页面底部的筛选标签（时间范围、全部/回复/规划/…）点击切换后，页面滚动位置跳到最顶部，影响继续浏览。3.20 已尝试保持滚动比例，但实测仍会跳。

## 目标

点击底部筛选标签切换后，页面保持当前滚动位置（内容高度变化时按比例或锚点补回），不跳回顶部。

## 实现

1. 定位底部筛选标签的点击处理与 `loadTimeline`/`renderTimeline` 的重绘路径，找出重置滚动的位置（可能是 `scrollTop = 0`、重新挂载列表或 `startPageEntrance`）。
2. 切换前记录 `scrollTop` 或比例；重绘后恢复；首次进入和点「刷新」仍回到最新（保持现状）。
3. 不改变缓存、预取与数据加载逻辑。

## 改动一览

只改 `aureus/web/static/index.html`：

- 新增 `timelineScrollablePosition()`：页面还能滚动时返回当前的整页滚动比例，不能滚动时返回 `null`。
- 新增模块变量 `timelineScrollMemory`：记住最近一次页面还能滚动时的位置。
- `applyTimelineData()` 的 `preserve` 分支在 `renderTimeline()` 前读取位置：能滚动就更新记忆，不能滚动就沿用旧记忆；重绘后按记忆的比例恢复。
- `latest` 分支（首次进入、刷新）仍滚到最新，并清空记忆，不沿用上次筛选的位置。
- 没有改 `loadTimeline` 的缓存、预取、请求去重和数据加载。

原来的 3.20 比例保持只在「切换前后页面都能滚动」时有效。筛选结果为空或很短时，列表加摘要和工具条不足一屏，页面 `scrollTop` 会被浏览器压到 0；再切回有内容的筛选时读到的就是 0，位置因此丢失。现在把上一次还能滚动时的比例保留下来，等内容重新变长后再补回，连续经过多个空/短筛选也不会把位置丢在顶部。

## 验收

- 在列表中部点击任意底部筛选标签，滚动位置保持（允许因内容高度变化有轻微比例差异）；连续切换不累积跳动；刷新仍回最新；深浅主题与窄屏正常。

### 实现说明

- 位置在 `renderTimeline()` 前读取（重绘前的页面状态），页面能滚动时更新 `timelineScrollMemory`，不能滚动时沿用旧值；这样空/短筛选不会把记忆覆盖成 0。
- 没有改成记录单条记录 id 的锚点：比例方式与 3.20 的现有实现一致，改动小，非空筛选的实测差异在 0.8% 以内；空筛选往返由记忆补回。
- 刷新和首次进入仍走 `latest` 并清空记忆，保持「回最新」的现状。
