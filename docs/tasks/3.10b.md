# 3.10b · 选择收件箱会话并持续聊天

状态：待评审

先读 D94、3.10a、开发守则。第 14、16、17 项由维护者确认。阅读限额和收件账号权限沿用 3.10a。

## 行为和验收

- 空闲时将允许访问的未读会话名称、类型、数量交给规划器。优先选一条私聊，再选择零个或多个群聊，每次合计不超过配置的阅读限额。会话正文随后各自进入回复规划。
- 规划器可以留在当前平台会话等新消息，也可以退出。可唤醒的特别关心来信在另一个会话进入时，当前会话让出注意力。维护暂停期间应继续保存消息。
- 默认关闭防抖。开启时规划请求用服务商的流式接口，同一轮消息等待默认四秒合并。规划请求期间，同一会话来信可取消请求并重开，单轮默认最多四次。已取消请求由安全网关记账。
- 各精力档位都先供规划器决定。沉默和看不懂的规划不给回复器。
