# 3.14 · QQ 表情包收集、选择、发送及旧库迁移

状态：实现中

## 路线与验收

1. 对照已安装版本的 MaiBot 表情包逻辑与 Emoji Text Selector 插件的源码，记录版本、来源、许可证、触发条件、选择策略和配置默认值。实现收集、去重、登记及使用状态，使新增和迁入表情都能从学习页浏览。
2. 将表情选择与实际 QQ 图片发送接入当前回复流程。使用假器官和模拟 OneBot 验证触发、选中、无候选、拒绝发送及文字和图片的顺序，保持会话和权限边界。
3. 核对现有迁移目标、归档媒体和表情来源，按稳定来源或内容哈希增量恢复缺少的登记和文件。保留原始文件、元数据、已有状态和缺件记录。对正式目标使用一致性备份或可逆的附加写入，记录前后数量、可读文件数和重复运行结果，不把私人内容加入仓库。

各项仅做专项验收。源码参考、正式数据操作和合成数据测试分别记录。
