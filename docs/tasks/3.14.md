# 3.14 · QQ 表情包收集、选择、发送及旧库迁移

状态：实现中

## 路线与验收

1. 对照已安装版本的 MaiBot 表情包逻辑与 Emoji Text Selector 插件的源码，记录版本、来源、许可证、触发条件、选择策略和配置默认值。实现收集、去重、登记及使用状态，使新增和迁入表情都能从学习页浏览。
2. 将表情选择与实际 QQ 图片发送接入当前回复流程。使用假器官和模拟 OneBot 验证触发、选中、无候选、拒绝发送及文字和图片的顺序，保持会话和权限边界。
3. 核对现有迁移目标、归档媒体和表情来源，按稳定来源或内容哈希增量恢复缺少的登记和文件。保留原始文件、元数据、已有状态和缺件记录。对正式目标使用一致性备份或可逆的附加写入，记录前后数量、可读文件数和重复运行结果，不把私人内容加入仓库。

各项仅做专项验收。源码参考、正式数据操作和合成数据测试分别记录。

## 源码与协议核对

- MaiBot 安装版 1.3.15，GPL-3.0，部署与许可记录见 `docs/13-references-and-migration.md` 第 2.5 节及 `THIRD_PARTY.md`。表情管理实现和默认配置以同上游公开源码 `062d45c` 的 `src/emoji_system/emoji_manager.py` 与 `src/config/official_configs.py` 为参考。收集候选按 SHA-256 去重，定期维护检查收集开关和已登记数量，按配置描述、审查、登记或替换，发送后按哈希更新使用统计。源码默认开启收集及替换，维护间隔 10 分钟，最多登记 64 张，单张上限 5 MB，内容审查关闭。默认采用独立选择发送，视觉直选开关 `use_new_send_logic` 默认为 `false`，视觉直选候选数为 25。未读取运行配置。见 [表情管理](https://github.com/Mai-with-u/MaiBot/blob/062d45c/src/emoji_system/emoji_manager.py) 和 [配置定义](https://github.com/Mai-with-u/MaiBot/blob/062d45c/src/config/official_configs.py)。
- 安装版 Emoji Text Selector 2.1.0，清单声明 GPL-v3.0-or-later、MaiBot 1.0.0 至 1.99.99、SDK 2.0.0 至 2.99.99。`plugin.py` 通过宿主的表情、近期消息、模型和发送接口工作，Python 依赖 NumPy、`maibot_sdk` 和 Pydantic。默认发现 `select_emoji` 工具并过滤原生 `send_emoji`，接受可选情绪提示，候选标签上限 50 个、近期消息上限 30 条，文本模型使用 `emoji` 任务，单次发送 1 张。语义匹配默认关闭，缓存刷新 300 秒，余弦阈值 0.3，向量批量上限 64，表情拉取并发 10；无情绪提示时使用对话前 500 字，未匹配或未发送成功时使用文字选择。见 [插件源码](https://github.com/hsd221/maibot-plugin-emoji-text-selection)。
- 安装版 SnowLuma Adapter 1.1.8，清单声明 GPL-v3.0-or-later。入站 `codecs/inbound/message_codec.py` 检查图片 `sub_type` 或 `summary`，数字子类型 `0`、`4`、`9` 和通用摘要 `[图片]` 单独出现时均不作表情标记。出站 `codecs/outbound/segment_encoder.py` 对自定义表情编码为 `image` 段，`file` 以 `base64://` 开头并携带 `sub_type: 1`。Aureus 的模拟收发均核对这一表示。
- Aureus 使用原有心跳、器官和安全网关，收集及选择默认开启。选择由通过最终回复检查的 `select_emoji` 建议触发，`before_text` 决定投递顺序。文字选择使用 `[organs.emoji]` 或现有回复器，任务名为 `emoji`。语义匹配默认关闭，默认刷新 300 秒、阈值 0.3，缓存按需在内存更新，语义无结果时走文字选择。平台拒收表情时保留文字发送，使用次数仅按成功回执更新。表情的描述和登记沿用现有视觉器官和媒体安全入口，学习页使用同一表情库查看登记、禁用状态与媒体。

## 正式库迁移验证

迁移使用测试 bot 的暂存记录和正式历史库已归档媒体，按稳定来源键新建表情来源，以 SHA-256 共用媒体资产。持有实例独占锁并用 SQLite 备份 API 建立同级备份（250,441,728 字节，`quick_check=ok`）。新增 2,412 条来源与 2,412 项独立资产；重复发布均新增 0 条。`memory_history` 前后均为 182,373 条，正式库 `quick_check=ok`。

5,941 条历史影像中，2,412 条标记为 `EMOJI`。这 2,412 条均可关联正式历史记录，2,412 份附件均通过摘要和 PNG、JPEG、GIF 或 WebP 文件头检查，实际缺件 0。旧状态迁入后为已登记 419、禁用 1,425、其余 568。其余中 1 条保留旧历史的 `missing` 状态，现有附件可读。历史使用次数沿用 `query_count`，504 条保留最后使用时间。正式实例未重启，迁移验证未使用真实器官或 QQ 发送。
