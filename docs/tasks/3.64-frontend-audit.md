## 实施接口与子步骤 A：审查夹具（不随产品发布）

先只准备审查环境。在审查副本外的 `build/ui364/` 中制作本机预览脚本；不要改产品代码。Python 标准库优先，允许复用现有测试夹具的纯假数据。提供一个明确端口的回环 HTTP 假服务（默认 18364），从传入审查副本 `aureus/web/static` 读取真实静态资源，只服务 `/`、`/assets/…`、`/learning-workbench/…` 等明确的静态资源；确保静态根有边界、不列目录，未知接口 404。不挂项目根、不启动 ASGI 主应用/内核、不读配置/密钥/数据库、不连接正式实例/外部服务。只使用编造的会话与文字，访问状态直接返回已通过的合成会话，不需要输入任何口令，不改生产鉴权。允许脚本按方案返回显式合成的常用读取接口、在登录、首页、长期记忆、学习、私聊、设置等展示代表状态；如果不能覆盖如实列出。不支持的写操作拒绝。对外部连接用测试页面 CSP 限制。可提供专用测试数据模式制造长文本/受控更新；不要用 DOM 改动伪造修复效果。给出启动参数、数据覆盖、局限，以及如何设置预览启动器。续写实现范围需先有证据。
