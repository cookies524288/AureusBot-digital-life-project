## 实施范围与分步验收

**A. 隔离预览（不随产品发布）**。只在 `build/ui364/` 使用本机回环假服务，展示 `aureus/web/static` 原版或候选版的真实静态文件；白名单以外的接口明确失败，不转发、不挂整个项目。样本全部编造，不连接 Aureus、不初始化真实内核、不读取任何实际配置或凭据。学习工作台从宿主页进入，不能用旧 iframe 测试代替。夹具静态缓存与推送均不代表生产环境。

**B. 收件箱历史后台刷新**。原版已缓存两页、显示 1–4，刷新第二页失败会变成只显示 3、4；重入时残缺结果被当成新缓存。任一页因临时错误失败应保留原有完整缓存、原时间戳与提示，重试从最新一页开始；没有缓存时保留已成功的第一页，重试续取历史。保持会话守卫、登录失效清理和翻页行为。`tests/web/test_inbox_refresh.py` 的登录过期用例只覆盖 401，不代表单会话读取权限变化已经验证。

**C. 输入状态**。`followConversationTyping` 将「收到布尔值 false」与「没有读到状态」混为一谈。未知（请求失败、超时、非布尔字段）立即收起气泡，但不消耗上次确认的 true，不触发补拉。当前平台会话 `true → 未知 → false → false` 各步累计补拉应为 `0、0、1、1`；推送已替换的气泡不得复活。沿用会话切换、离页、登录失效、明确拒绝时的边界和私聊原行为。正常停止和无查看范围都可能得到 `200 {"typing":false}`，不猜原因，补读仍走原授权接口；明确 403 不当作普通超时，也不当作全局登出。不改后端或轮询协议。

**D. 时间线和观察页**。`reply_reference` 带 `actions: []`，正文被无对应详情的「本轮行动记录」替代。只有详情真的呈现正文才替换摘要；无、空、非空数组均有读到结尾的路径。两页共用的长正文不能只绑定不可聚焦元素的 click，改用具有可见名称的原生控件，可展开、收起；保留文字选择、换行、已有行动详情和卡内其它操作。短文不多加按钮。测试多段中文、空行、1,024 个无空格字符及结尾标记。不写回记录。

**E. 人设历史**。前 60 字相同的两个版本，在回退前无法辨认。保留列表摘要；原文被截短或段落被压平时提供单独、可收起的只读全文，保留原换行。用两个结尾不同的合成版本验证结尾和零写入；展开与收起均不确认、不触发回退。「用这个版本」的原有锁和确认不变。不改人设内容。

**F. 字段标签**。各层人设文本框关联已有层名；设置编辑器已有无障碍名称，但可见标签没有关联控件。使标签原生关联自己的输入框或选择框；同时存在多个字段时不可错指。保留既有标识、无障碍名称、禁用与保存行为。

**G. 主题文字对比**。按 UI/UX Pro Max 的普通文字 4.5:1 规则，验证实际 CSS 选择器的实色配对。基线浅色主按钮常态 2.98:1，桌面侧栏普通文字 3.59:1。只改这些角色及它们的正常、悬停、选中状态，不改全局强调色、字体、像素砖块和手机整屏边框。暗色配对不得退化；注意带有其他颜色角色的按钮及学习工作台的样式隔离。列出选色计算；不能据此宣称真实渲染已经通过。

C–G 只改负责的发布页面和必要的新增回归，优先复用已有辅助函数或 HTML 原生控件；不改老测试来求绿，不加产品测试开关。功能语义与实际屏幕上的焦点、可点击面积、文字溢出分别验收。

**H. 前台恢复（3.43）**。可见时间线/平台/观察/总览/长期记忆本已有对应推送刷新；若去抖回调在页面隐藏时运行，缓存虽失效，返回时却没有补刷时间线的入口。以正常事件、假时钟和已注册的页面可见性监听器先复现；确认后对仍在同一登录会话、同一页面且确有相关后台事件的情况，恢复前台只补一次。没有变化/无关主题不新增请求，不恢复已离开的页面，不给学习页另加推送，不改协议。观察页既有每 10 秒四次读取不应在不可见时为后台画面渲染。暂停期间有待获取的观察数据，恢复只追新一次；不新建后台轮询。

**I. 会话最新列表变空**。分别核对临时错误和成功的空列表，不靠 `typing: false` 猜原因。产品最新页接口不带游标时可能正常返回 `messages: []`、无后续页；该时刻当前列表已没有可显示消息。若已显示旧消息的增量刷新把它当作无变化，须清掉这个会话的已见键、旧显示和旧消息缓存，避免在途的更早读取把它重新显示出来；不影响其他会话。普通失败保留旧历史，翻到末页出现空列表不等于整个会话变空，迟到的旧会话结果不得修改新会话。仅UI及正常合成数据；不检查真实权限、不改后端。先用原版行为复现再修。

**J. 推送不能打断正在读的长文**。在 `2c04629` 上按真实页面函数展开一条 300 字记录，再送入一条正常的时间线变更；新记录到达的同时，原文从末尾退回摘要。只在当前时间线的自动更新中，保留仍在结果里的同一记录的正文展开、规划详情展开，以及原先就在这些控件上的键盘焦点；不抢别处焦点，不保存正文第二份，不跨登录或给已离开页面的回调重上焦点。仅在正在阅读时保留位置，其他首次进入、筛选和回到最新沿用 3.35。观察页原有行复用不变。用同开头但不同 ID 的编造记录、已收起/已移出结果的记录验证身份不串。

**K. 状态标签和表单中的低对比文字**。G 的末次检查发现：亮色普通标签的 12px 文字 `#6b7f85` / `#f2ebd6` 只有 3.53:1；人设历史摘要和字段标题在 `#fffaeb` 上为 4.03:1。亮色实色标签的强调、成功、警告、危险配对分别只有 4.09、3.61、3.72、3.67:1，相同配对也用于提示条。只修这些可确定的文字角色及同实色读写字段，不动标识色背景、图标、警示色含义、像素边框或暗色既有合格配色；次级字的层级保留。核对层叠优先级，保证 info/danger 等变体不互相覆盖，实色普通文字至少 4.5:1。纹理、混色、禁用及实际屏幕焦点另验，本步不把抽样工具当整站无障碍证明。

**A 的交接样本**。预览器仍只服务回环和固定静态文件；补进合成长规划（缺省、空与非空 actions）、两个同前缀不同末尾的人设版本。让正常首页、主界面 → 观察/时间线/人设的维护者回归不再只看到空样本。不要模拟真实写入、身份或导入个人资料，不改发布文件。

### 补测小步：M 实色文字、N 极长内容、O 筛选状态

- **M. 实际阅读路径上的实色配对**：G 修了金色主按钮，但私聊与平台共用的 `.msg.user .bubble` 仍是同一组不足 3:1 的正文。时间线筛选普通和选中、私聊输入提示、模型库厂商地址和计数（包括选中/悬停）、模型紧凑卡副文案、模型开关说明、弹窗说明、长期记忆卡摘要及来源文字，也仍在实色底上使用旧颜色。只修这些已定位的文字角色；危险操作按钮的文字在深浅常态和悬停都须达到普通文字 4.5:1，30px 删除图标本身与红色底至少 3:1。优先复用已有语义色，不改全局强调、装饰边框、图片、禁用透明度、Shadow DOM 或数据。对实际 CSS 选择器与有效前景/背景核算两种主题（含悬停中的选中厂商），不以取色数据声称实屏通过。
- **N. 会话名和观察状态长串**：`.btn` 禁止折行，平台会话名虽有 `overflow-wrap` 仍继承 `white-space:nowrap`；未读数会被超长名称挤出按钮。仅让名称文字项能缩小并换行，未读数保持独立且不缩；列表不裁去全文。观察面板 `#mo-state`、当前任务 `#mo-task` 继承的 `pre-wrap` / 普通换行不能拆开无空格标识，祖先面板又裁溢出：允许在必要时折行，保留显式换行、不裁尾。复核普通短文本、1,024 字与未读数的生成路径。布局证据分别登记：源码规则不是实际按钮热区或截图。
- **O. 时间线筛选的选中状态**：渲染原生筛选按钮时，使用读屏软件能够识别的按下状态（`aria-pressed`）。首次、切到另一项、重复点击当前项及重建按钮后，恰有一项被按下，须与实际请求筛选、可见选中样式同步。按钮原地更新、保持键盘焦点；重复点击不额外取数，不改变分页和已有加载策略。编造筛选记录测试，不发真实请求。

### P. 事件之前的慢响应不能当成事件之后的时间线快照

在 `d061f92` 用实际注册的 WebSocket 回调、合成 fetch 和假时钟复现两条路径：① 时间线读取未结束时，收到变更，再过 250ms；两次读取合并为 **1 次 GET**，最后仍显示变更前的摘要。② 在人设页预取时间线，收到时间线变更，旧预取稍后返回；进时间线只发过 **1 次 GET**，过时的摘要被当作新缓存。仅修时间线：变更后必要的读取不能复用变更前的同一快照；晚到的旧预取/页面读取不能在新版显示后覆盖缓存或画面。非当前页不因事件立刻发请求，进入或恢复前台时才取；同一代的并发读取仍可共享，短时间内多次事件仍合并，不因无关主题丢弃在途读取。不改后端协议、URL、全局缓存 TTL、学习页或数据授权，不加轮询或补偿性重试。定向回归应覆盖两种快照返回顺序（含切页前后的旧预取）、当前与非当前、无关事件及同代去重；使用真实页面事件回调和可控响应，不调用正式实例。其他业务页的在途快照不以这项测试冒称已经验证。
