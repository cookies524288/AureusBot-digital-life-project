# 3.44 平台会话左侧列表与右侧窗口等高

状态：待实现
设计：维护者 2026-11-26 指令

## 目标

平台会话页左侧的会话选择列表高度与右侧会话窗口一致，底部对齐，不留短一截。

## 实现

1. `aureus/web/static/index.html`：调整 `.inbox-layout` 网格与左右卡片高度（`align-items: stretch`、`height: 100%` 或 `min-height` 对齐），列表内部滚动。
2. 窄屏保持上下堆叠，不强制等高。
