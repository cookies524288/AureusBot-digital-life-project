## 独立运行约定

语言材料由记忆子系统持有，使用运行主库中的独立表。Planner 看近期人类消息命中的黑话，Replyer 按当前消息、Planner 意图和说话人选择表达。条目与证据按全局来源定位，通道只用于标识说话人和投递来源。

新入站的时间线消息交给独立学习步骤。学习和召回有各自的开关，默认开启召回、关闭学习。配置的器官按可选调用经安全网关返回提议，记忆子系统核验证据、区分新习得和再次观察。通道有稳定消息编号时由通道、说话人和消息编号去重，否则使用本地时间线编号。

发布调用 3.2 的正式暂存读口，由语言库事务写入。发布键使用实例、角色、源表与原始主键。按源包清单锁定一个实例的已发布快照，换快照时另用目标库，保留首次验收的数据边界。暂存与运行库都保留源标识，黑话通过平台与消息编号解析证据，不写时间线。

## 3.6a 提示词登记

固定文本集中在 `aureus/common/language_prompts.py`，模板登记时沿用下列变量和注入点。

| 固定文本 | 注入位置 |
|---|---|
| `LANGUAGE_PLANNER_EXPRESSION_INTENT` | `context.build_plan_prompt` 的基本规划指令之后，语言召回启用且有字数预算时注入。 |
| `LANGUAGE_JARGON_HEADER`、`LANGUAGE_JARGON_ITEM`、`LANGUAGE_REFERENCE_NOTE` | `language_matching.format_language` 根据黑话命中组成参考块，每行用 `text` 和 `detail`。由 `context.build_plan_prompt` 注入到近期对话之后，合并调用时由 `context.build_reply_prompt` 注入。 |
| `LANGUAGE_EXPRESSION_HEADER`、`LANGUAGE_EXPRESSION_ITEM`、`LANGUAGE_REFERENCE_NOTE` | `language_matching.format_language` 根据表达命中组成参考块，每行用 `text` 和 `detail`。由 `context.build_reply_prompt` 注入到对话及普通记忆参考之后、回复意图和长度之前。 |
| `LANGUAGE_LEARNER_PROMPT` | `language_runner.learn_language` 构造可选器官请求，模板变量是 `max_text`、`max_detail` 和 `samples`。 |
