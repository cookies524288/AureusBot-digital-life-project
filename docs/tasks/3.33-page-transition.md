# 3.33 恢复切页过渡动效，不影响缓存

状态：待实现
设计：D133、D129（docs/10-decisions.md）

## 先读

- `aureus/web/static/index.html`：`showPage`、`startPageEntrance`、`pageEntrance`、`state.entranceSeen`（性能收尾时加的「只首次播放」逻辑）、页面缓存与预取。

## 目标和验收

1. 每次切换页面都播放原来的入场动画（淡入 + 轻微上移），不再只在本次登录首次进入时播放。
2. 缓存内容立即出现，动画只是视觉过渡；不重新请求数据，不改变预取、缓存 TTL 与写后失效。
3. 减少动态偏好（`prefers-reduced-motion`）时仍然不播放动画。
4. 切页期间没有明显卡顿或长任务；窄屏与深浅主题正常。

## 改动一览

- `aureus/web/static/index.html`：去掉「已播放页面」跳过逻辑，恢复每次切页播放；必要时限制动画元素数量。

## 行为细则和边界情况

1. 动画只作用于当前页面容器与首屏可见元素，避免整页文字扫描造成长任务；可沿用现有 `startPageEntrance` 的可见性观察。
2. 缓存命中时先渲染内容，再启动动画；动画不得延迟内容可交互时间。
3. 快速连续切页时取消上一页动画，不叠加。
4. 不做：改变缓存、预取、页面数据加载逻辑。

## 测试
