- 本机活动 OneKey 安装是 MaiBot 1.3.15、`maibot-dashboard` 1.9.9。只核对安装包的程序代码，不读数据库、会话、账户、密钥或日志。公开源码固定在 `062d45cf8bd4272ac57d7ec03fcf405e5a458211`。本机 `src/learners` 的八个 Python 文件中，两个 learner 不同于公开提交，包含本机的学习排除逻辑；不把本机私人列表、样本文字、路径带入仓库。实际使用的前端资源为 `maibot_dashboard/dist`，学习 chunk 的 SHA-256 是 `6337b1ad95901d1c7f980c337e951d8315a21f61b87d7783ffce60aad836001f`。没有源映射；以固定版可维护的 TSX 构建，以安装包验证操作，不声称构建逐字节相同。
- 前端起点 `dashboard/src/routes/resource/learning/index.tsx`，依赖表达、黑话、表情三页及其组件、长文学习、公共 hooks、API、分页与弹窗。后端起点 `src/learners/`、`src/chat/replyer/{maisaka_expression_selector,expression_vector_index}.py`、`src/maisaka/jargon_context_matcher.py`，以及 `src/webui/routers/{expression,jargon,emoji,text_learning}`、相关 services、模型和迁移。学习不依赖整个 A_Memorix 的启动。许可证分别依据固定仓库 GPL-3.0 和 dashboard AGPL-3.0；保留许可、逐文件来源和修改记录。不能仅提交压缩 JS、孤立上游源码快照或整套未使用的机器人。

## 前端操作逻辑与接口清单

## 实施与交付证据

### 2026-11-25 组合验收与接口约定

- 表达、黑话、表情的列表、统计、编辑、定性及导入导出沿用固定版 `src/lib/*-api.ts` 的请求与响应；不得只在 Python 测试中使用另一种请求形式。已复现两处缺口：表达统计缺 `recent_7days` 会使原页面渲染报错；原黑话批量定性以 query 参数发送，当前仅接受 JSON 的接口返回 422。两者仍待修复，不以此前 11 项单独 API 专项代表页面可用。
- 簇与向量由后端适配到原 `/api/webui/expression/clusters`、`/clusters/{id}/members?profile_marker=…`、`/runtime/vectors/spaces`、`/vector-build-progress`。前端保留原组件和操作；不能从只包含文字的旧 `/api/resources/learning/clusters/detail` 猜测整数编号、统一填 `id=0` 或用簇编号冒充表达编号。成员由获准的原件键映射到工作台稳定编号，快照/权限改变后拒绝旧定位；原旧端点继续只返回原有公开字段。
- 独立表达质检使用已存在的 `/api/resources/learning/quality`，保留来源、状态/日期筛选、分页以及挽回/撤回的预览和确认；不要为已经移除的人工精选界面再造一套同义 API。质检建议不是人工批准门槛，但模型拒收和来源证据仍有实际作用。
- 新工作台的真实页面必须连接合成数据库上的实际 ASGI 路由。原页可渲染、编辑后列表和回复读侧一致，才完成该操作的验收。浏览器拦截合成响应只证明前端局部交互；空数据库契约测试、编译成功、接口返回 200 不能代替此项。
- 目前缩略图缓存、批量上传专用端点、旧版数据库导入、覆盖导入及向量维护等尚缺的操作，标为“未完成”；返回 409 或暂时禁用只用于实施期间如实暴露缺口，不是维护者批准删去这些功能。用户已允许在保留现有原件、来源与授权的前提下整体移植，继续补齐宿主适配。
- 默认值与实际学习触发还须分别对照已授权的标量清单及固定源码：最低素材量、每批上限、裁切历史触发、间隔、并发与词频统计不得仅以有界队列和定时器声称等价。旧用户保存的配置不覆盖；当前目标以学习与表达模块为限，不扩展到长期记忆内核。
