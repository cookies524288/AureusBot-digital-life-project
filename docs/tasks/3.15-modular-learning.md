## 源码基线与范围

- 本机活动 OneKey 安装是 MaiBot 1.3.15、`maibot-dashboard` 1.9.9。只核对安装包的程序代码，不读数据库、会话、账户、密钥或日志。公开源码固定在 `062d45cf8bd4272ac57d7ec03fcf405e5a458211`。本机 `src/learners` 的八个 Python 文件中，两个 learner 不同于公开提交，包含本机的学习排除逻辑；不把本机私人列表、样本文字、路径带入仓库。实际使用的前端资源为 `maibot_dashboard/dist`，学习 chunk 的 SHA-256 是 `6337b1ad95901d1c7f980c337e951d8315a21f61b87d7783ffce60aad836001f`。没有源映射；以固定版可维护的 TSX 构建，以安装包验证操作，不声称构建逐字节相同。
- 前端起点 `dashboard/src/routes/resource/learning/index.tsx`，依赖表达、黑话、表情三页及其组件、长文学习、公共 hooks、API、分页与弹窗。后端起点 `src/learners/`、`src/chat/replyer/{maisaka_expression_selector,expression_vector_index}.py`、`src/maisaka/jargon_context_matcher.py`，以及 `src/webui/routers/{expression,jargon,emoji,text_learning}`、相关 services、模型和迁移。学习不依赖整个 A_Memorix 的启动。许可证分别依据固定仓库 GPL-3.0 和 dashboard AGPL-3.0；保留许可、逐文件来源和修改记录。不能仅提交压缩 JS、孤立上游源码快照或整套未使用的机器人。

## 一个模块，三个接入边界

|边界|应当保留的完整行为|宿主适配和验收|

|资料与 HTTP|逐一登记页面实际触发的 method、路径、参数、响应、错误、授权和落库效果；以同一模块的权威资料驱动 Web 和运行时。检查 `expressions`、`jargons` 及依据、复核日志、图片资产、向量与管理索引的表／库外文件；老数据、主键和设置不可丢失。|一个角色数据根、一个共享学习库，不按会话另建库；来源/证据键、主动移除、撤权和同名义项边界仍保留。既有存量通过同一 repository 适配，或经带预览、可回退的明确迁移，不以双写替代。不得把具体聊天原文当作可检索记忆，不将客户端路径、接入令牌或包自报授权作为可信输入。|
|学习与真实消费|两类后台学习的取样、批次、过滤、质检、证据、重新推断、相似项更新、候选排序、向量空间、簇、实际回复注入；采用活动版中已核实的白名单参数，不忽略数组字段的功能，也不搬个人名单。|将消息、授权、时钟、会话来源、sqlite 连接、图片存储及模型调用映射到本项目，不能在 import 时启动上游服务或打开 MaiBot 库；所有模型调用走既有预算与安全网关。在关闭和热切换时回收任务，不向正式 QQ 发消息。|

## 前端操作逻辑与接口清单

不是把原页嵌入后接几支 CRUD API。应从 `dashboard/src/routes/resource/learning/index.tsx`、各业务页、hooks、dialogs、`src/lib/{expression,jargon,emoji,text-learning}-api.ts` 追踪用户动作，并把原 React Query 缓存与无效化、路由页签、表单状态、所选项、确认弹窗、加载/错误提示及操作后刷新整体保留；宿主登录、主题、导航和统一资料/数据安全边界适配 Aureus。不能以主页面能打开、API 返回 200、空占位数组或假成功状态视为操作已移植。

|用户可执行的前端操作|固定源码接口族|Aureus 必须呈现的真实结果|
|---|---|---|
|表达页筛选、跨页批选、详情/新建/编辑、可逆移除/恢复、导入导出和旧格式导入预览；簇浏览和授权；质检记录、原来源挽回|`/expression/{list,chats,chat-targets,groups,stats/summary,clusters,clusters/{id}/members,review/stats,review/list,review/batch,review/logs,review/logs/{id}/approve}`；`/{id}`、`/`、`/{id}/review-status`、`/batch/delete`、`/export`、`/import`、`/clear`、`/legacy-import/{preview,preview-file,import}`、`/runtime/vectors/spaces`、`/runtime/vectors/spaces/{id}`、`/vector-build-progress`|分页、搜索、聊天/群组、排序、审核视图与选择状态使用实际同一库数据；更改/撤回在实际回复读侧生效；簇和向量必须走宿主现存索引，不能硬编码空结果；质检挽回依然服从安全来源约束。D109 免表达人工审批是政策变化，不得重新作为回复资格门槛；表达质检/挽回与旧人工批准状态严格分离。无法移植的旧数据库路径导入须改为同源文件上传和安全预览，不接受任意本机路径。|
|黑话页筛选、跨页批选、详情/新建/编辑/移除、黑话/非黑话定性、导入导出|`/jargon/{list,chats,groups,stats/summary}`、`/{id}`、`/`、`/export`、`/import`、`/batch/delete`、`/batch/set-jargon`|词条及多个义项不丢失、不把来源不同的同词义项错误合并；定性是独立资料字段，不是回复批准，也不能阻止合格资料被学习/候选消费。共享组接口如无宿主对应须明确报告“不支持”而不是伪造空配置。|
|表情页筛选、排序、跨页批选、详情/描述修改、右下审批、登记/封禁/移除、上传/批量上传、缩略图缓存维护|`/emoji/{list,stats/summary,upload,batch/upload,batch/delete,thumbnail-cache/{stats,cleanup,preheat,clear}}`、`/{id}`、`/{id}/review`、`/{id}/register`、`/{id}/ban`、`/{id}/thumbnail`|每个卡片右下角保留独立审批按钮与确认/反馈；原件、缩略图、登记/禁用状态与缓存操作均落到宿主表情库/受控素材目录；不可管理路径或缓存统计不实回显。|
