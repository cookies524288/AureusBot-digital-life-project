## 目标与验收

- 日期框是尚未提交的草稿。快捷查询在等待期间只要有任一日期被编辑，就不覆盖两个日期框；「刷新」才把手填范围应用到请求。
- 没有新编辑时，当前快捷查询回填服务器给出的起止时间。无论是否回填，本次结果的翻页都沿用该范围，不能重算快捷窗口或误用草稿。
- 连续点击两次快捷查询时，以最后一次发出的查询为准；迟到结果不得覆盖草稿、列表或分页范围。
