## 目标和验收

学习页本身就是完整工作台：没有 iframe、没有「打开完整学习工作台」按钮；布局、页签、筛选、列表、详情、批量操作与工作台一致；控件是 Aureus 的圆角风格；只有全局范围。

验收：

1. 学习页加载后直接显示工作台，URL 不因工作台内部页签变化而改变。
2. 工作台样式不污染主页面（主页面按钮、卡片、字体不变）；工作台内按钮/输入框为圆角，与 Aureus 一致；深浅主题跟随主页面。
3. 聊天范围面板隐藏，接口始终按全局范围调用。
3a. 工作台内部的滚动条也使用与主页面一致的细胶囊样式（宽度约 8px、透明轨道、两端全圆的纯色滑块，不做渐变），深浅主题跟随；鼠标靠近时滑块自动变粗，与主页面一致（见 [3.21](3.21-scrollbar-hover-expand.md)）。
4. 表达、黑话、表情三页的列表、筛选、详情、新建/编辑、导入导出、批量操作、长文学习均可正常使用（沿用现有接口）。
5. 移除 iframe 与「打开完整学习工作台」入口后，原 `learning-workbench` 构建产物仍由同一构建流程生成。

## 改动一览

- `frontend/maibot-learning/src/main.tsx`：路由改内存路由；挂载到宿主（`window.__aureusWorkbenchHost` 或页面传入的元素）；主题类挂在宿主上。
- `frontend/maibot-learning/vite.config.ts`：入口与 CSS 输出固定文件名（如 `workbench.js`、`workbench.css`），便于主页面动态加载。
- `frontend/maibot-learning/src/host.css`、`index.css`：圆角与配色映射到 Aureus；`:root`/`html` 规则改为 `:host` 兼容 Shadow DOM。
- `aureus/web/static/index.html`：学习页创建 Shadow DOM 宿主，按需加载工作台 CSS/JS；删除 iframe 与入口按钮。
- `aureus/web/server.py`：如需按固定文件名提供资源，补充静态路由。

## 行为细则和边界情况

1. 内存路由：页签状态保存在路由内存中，刷新页面回到默认页签；不修改 `location.hash` 或路径。
2. Shadow DOM：宿主元素 `#learning-workbench-host` 由主页面创建；CSS 以 `<style>` 注入 shadow root；工作台 JS 通过 `window.__aureusWorkbenchHost` 拿到根节点。Tailwind 预检若含 `:root`/`html`/`body`，构建后改写为 `:host`。
3. 主题：主页面切换深浅色时，给宿主加/去 `dark` 类和 `data-dashboard-style`；颜色变量映射到 Aureus 的 `--accent` 等；圆角映射为 Aureus 的 `--radius-sm/md/lg`。
4. 聊天范围：在宿主上设置全局标志（如 `window.__aureusWorkbenchGlobalScope = true`），工作台读取后隐藏范围面板，并让接口请求固定使用全局范围。
5. 失败回退：工作台加载失败时在学习页显示错误和重试，不退回 iframe。
6. 不做：修改学习接口、改变学习数据、重写工作台组件。

## 实现说明

- 工作台不再套用自带的千禧方形皮肤（去掉 `styles/millennium.css`），宿主设 `data-dashboard-style='aureus'`，让基础组件使用 Aureus 的圆角。
- Radix 浮层通过 `PortalContainerContext` 挂到 `#root`，保证对话框、下拉、Select 留在 Shadow DOM 内。
- 全局范围下 `DataBrowserLayout` 加 `data-layout='single'`，避免空出来的 14rem 侧栏列。
- 构建时把 `:root` 选择器同时展开为 `:root` 和 `:host(...)` 两种写法，独立 `index.html` 预览仍可用；`html/body/#root` 的尺寸规则补了 `:host`。
- 颜色用 `hsl(from var(--bg) h s l)` 相对颜色语法把主页面十六进制变量转成工作台需要的 HSL 三元组；主页面在 `#page-learning` 上提供 `--workbench-*` 别名，避免工作台自己的 `--border`/`--accent`/`--radius` 同名变量截住取值。
- 删除主页面里已被工作台取代的旧学习/表情 UI 与脚本，保留长期记忆共用的 `mediaTile`/`fullImage` 等函数；未改后端接口、学习数据和 `docs/10-decisions.md`。
