# 3.10a · 分会话翻阅平台收件箱

状态：实现中

先读 D94、3.10 的验收记录和开发守则。实现范围为收件箱分页、心跳选取、规划和管理网页的阅读上限。

## 验收

- [ ] 自主翻阅优先选择未读私聊，并使用剩余条数选择一个或多个群。合计上限默认 35 条，配置范围为 1–200，重启生效。同类会话按最早未读排序，持续收到新消息的会话也能被选中。
- [ ] QQ 当前权限在优先未读分页之前生效。绑定用户和特别关心的来信仍可唤醒。维护暂停时保留未读，恢复后再读。
- [ ] 选中的会话逐个规划，提示词标注源时间、已关联人物与实际发言者。回复保留会话回址。节省和低电量档位也须由规划器明确建议回复，规划失败时保持沉默。
- [ ] 存储的游标按每个会话保存。处理优先来信时，未处理的旧消息仍可翻阅。网页只读查询保持原有行为。

验证使用临时数据、手动时钟、假器官和模拟 OneBot。
