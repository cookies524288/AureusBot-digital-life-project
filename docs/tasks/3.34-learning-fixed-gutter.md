# 3.34 学习页始终留出导航展开宽度，悬停不再挤压内容

状态：待实现
设计：维护者 2026-11-26 指令（修正 3.23 的过渡方案）

## 问题

3.23 让学习页左内边距在导航悬停时从 56px 过渡到 224px。维护者实测：鼠标移到左侧，导航抽出并把右侧页面挤窄，按钮跟着移动，难以点击最左侧的按钮。

## 目标

学习页右侧内容始终停在固定位置，导航展开只覆盖左侧空白区，不挤压、不移动右侧内容。

## 实现

1. 桌面宽度（>820px）下，`#page-learning` 的左内边距固定为 `var(--nav-open)`（224px），不再随悬停变化、不再有 `transition: padding-left`。
2. 导航展开时覆盖这段预留空间，不遮挡工作台内容；导航收起时这段空间保持留白（可接受）。
3. 窄屏（≤820px）保持 `padding-left: 0`。
4. 其它页面不变。

## 验收

- 鼠标在左侧导航上移动、展开、收起时，学习页内容左边缘与按钮位置不变；无横向滚动；窄屏正常；深浅主题正常。
