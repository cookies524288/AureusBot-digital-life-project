# 路线图 3.6b · 设置逐项恢复默认

状态：待实现

先读 D91、D89、3.6a、网页配置接口与设置表单、安装时生成的配置和运行时加载入口。

## 子步骤

1. 按已有网页设置表单列出有项目默认值的可编辑参数，覆盖基础、高级、模型和器官等配置。记录默认来源、用户覆盖位置、加载时机。Prompt 交由 3.6a，生化参数交由 3.8，集成时一同验收。
2. 每项提供可键盘操作的“恢复默认”按钮，调用与编辑相同权限的后端。只删除该键的覆盖，重新读取当前版本默认。保留同组其他设置、未知键及用户数据。后续开发仅修改工程默认来源。检查新安装、旧配置、保存另一个字段是否意外把默认值固化为用户覆盖。
3. 用临时数据根目录从真实入口核对逐项修改、恢复和重启。显式写入的旧配置保留，来源无法判明的旧值按显式覆盖处理。

## 自检

- [ ] 各页有默认的可编辑设置逐项有恢复入口，盘点能对应到实际按钮。身份正文、账号、凭据、历史记录与运行命令不参与通用重置。
- [ ] 两项自定义只恢复其中一项，验证磁盘、返回值、重启后的实际加载值及另一项的值。
- [ ] 改动一个开发默认并重新加载，未覆盖和已恢复的项跟随更新，其余显式自定义保留；重复恢复同一项有效。
- [ ] 用浏览器验证编辑、恢复、刷新、权限和错误显示；专项检查通过。
