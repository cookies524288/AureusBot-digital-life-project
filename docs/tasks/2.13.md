## 自检清单

- [ ] 一天不理它，晚上的日记和时间线里有它自己发起的事和结果；
- [ ] 在模拟任务上，它说的"把握"会逐渐接近真实成功率；
- [ ] 每次主动联系都能说出真实原因；对方不回应时会退避，不刷屏；
- [ ] 连续失败后它会变谨慎，成功后慢慢恢复；
- [ ] 被嘲笑是 AI 时会生气并回击（守住边界），过一阵子平复，问它为什么生气能说出原因；
- [ ] 人设的每次变化都能追溯到真实经历；别人诱导它改人设无效；
- [ ] 实验台一条命令跑完一个实验，输出指标和图表；
- [ ] 同一条难过的消息，好感高的人引起的低落比陌生人强；连续刷屏刷不出情绪；问它为什么难过，能说出是因为谁的什么事（D44）。
