# 3.43 删除手动刷新图标，改用 WebSocket 实时同步

状态：待实现
设计：维护者 2026-11-26 指令（已确认用 WebSocket 推送、全删刷新图标）；可参考 MaiBot 公开源码（固定提交 `062d45c`，GitHub 取 raw 时走本机代理 `127.0.0.1:7897`）

## 目标

所有页面不再显示手动「刷新」图标；数据通过 WebSocket 推送自动更新，各处消息实时同步；刷新函数保留供内部事件调用。

## 实现

1. **后端**：扩展现有 `/ws` 通道，除聊天外推送数据变更事件（新平台消息、新时间线记录、轮次状态变化、学习/记忆资源变更）。事件只带类型与最小标识（不推聊天正文），按登录会话鉴权；实现方式可参考 MaiBot 的 WebSocket 做法，但要适配 Aureus 的事件源（心跳/收件箱/时间线）。断线自动重连，重连后补拉一次。
2. **前端**：订阅事件，按页面失效对应缓存并刷新当前页（非当前页只失效缓存，下次进入重新取）；保留现有页面缓存与预取，推送只做失效与增量刷新。
3. **刷新图标**：删除所有页面头部的「刷新」按钮；刷新函数保留（例如 `loadTimeline(false)`），由推送、写操作或内部定时调用。
4. 不推送私聊原文；权限与撤权语义不变；急停/停机时停止推送。

## 验收

- 各页面头部无刷新图标；新消息/新轮次在 1–2 秒内自动出现在对应页面；非当前页进入时数据是最新的；断线重连后自动补齐；Console 无未捕获异常。
