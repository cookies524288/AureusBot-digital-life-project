# 学习页按会话浏览黑话与表达

状态：待实现

## 先读

Phase 3.11 维护。先读 `docs/tasks/resource-page-ux.md`、`docs/tasks/maibot-learning-parity.md` 和已有语言包会话映射验收。参照固定版本公开 MaiBot 的黑话列表会话筛选、表达列表会话筛选；不要读取实际部署的会话、配置或数据库。

## 子步骤

1. 在黑话和表达列表提供按已知会话筛选的入口，保留默认的全部资料视图。使用已有会话映射和真实绑定关系，不以名称猜测，未绑定不等于全局。选择某会话时，共享给多个会话的条目只出现一次；不改变旧资料的召回或权限。
2. 在存储查询中先组合会话、文本、状态、审核等筛选，再统计条数和分页。筛选切换回第一页，空结果明确显示，延迟的旧请求不能覆盖新选择。说明筛选范围与当前召回范围的区别。
3. 用两个群和一个私聊的合成资料验证独立、共享和未映射条目、同名不同会话、组合筛选与真实总页数；验证取消筛选能回到原列表，浏览操作不写入资料、不改变任何召回结果。更新对照表，准确标出尚无等效实现的全局与旧会话语义。

## 不做

不更改原件、标签、会话授权和召回策略，不引入新的持久状态或第三方依赖。不借此发布未验收的其他改动，不操作正式实例或远程仓库。

## 自检清单

- [ ] 黑话和表达都能按明确绑定的会话筛选，共享记录只列一次；未映射资料不被当作已授权。
- [ ] 组合筛选先于计数和分页；切换会话与恢复全部视图不会显示上一个请求的结果。
- [ ] 存储、接口与窄屏浏览器合成专项通过，对照表列明覆盖与差异。
