# 3.15 · 设置查找、切页反馈和身份称谓

状态：实现中。对应[台账](3.15.md)第 11、12、13 项；分三个独立小步，不等待正式重启。先读 `aureus/web/static/index.html` 的 `CFG_FIELDS`、`cfRow`、`showPage`、私聊与人设，以及 `aureus/{identity/models,web/settings_api,web/config_files}.py`。分段送达与重连沿用[分轮时间线](3.15-timeline.md)，会话输入状态见[平台任务](3.15-platform.md)。

1. **设置查找**：以网页实际收到的运行配置 schema 为覆盖清单（不读正式配置）。每个可展示的节和字段要有真实的中文名、可悬停/键盘聚焦阅读的具体含义，技术路径作为补充而不是名称。只读或重启生效照实标出。左栏标签上方加入本地即时搜索；按中文名、节、技术路径和说明匹配，定位到实际编辑控件。包括已有的浏览器字体；不把隐藏设置、密钥或密码放入索引。不因搜索、清空、切节丢弃未保存值、无效的输入或焦点；没有匹配时可以清空返回。不要为搜索制造另一套表单或向后端发请求。
2. **切页状态**：同步提交目标页/页内标签的选中及禁用状态，再开始入场动画和异步加载。保留原有像素按下样式，包括键盘和减少动态偏好。排查导航也排查在新页面里已经禁用的保存、当前页、还原等按钮：入场动画不能以另一种位置或阴影掩盖真实按下态。只锁本来不可点的控件，其它页、翻页、跳页即使上一请求未返回仍可用。旧加载或动画结束不得逆转新状态。
3. **性别与称谓**：只有用户可改身份。新建身份为「男」，编辑仅提供「男/女/其它」，分别展示「他/她/Ta」。旧自由文本和空值可读；旧值未知时按 Ta 展示，不在启动、看页面或保存无关信息时替用户改写。身份展示数据走已有认证接口，切换账户、退出、保存后更新。检查产品文案（人设、聊天、时间线、观察、CLI 等）中指代 bot 的「它」，不要对消息、模型产出、历史资料、提示词引用原稿和指物的「其它/它们」全局替换。私聊每条已投递的分段独立气泡；实时、历史和重连使用同一分段键，未投递草稿不展示。
