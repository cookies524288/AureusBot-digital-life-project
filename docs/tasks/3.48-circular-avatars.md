# 3.48 所有头像改为圆形

状态：待实现
设计：维护者 2026-11-26 指令

## 目标

项目网页里的所有头像（会话消息头像、平台会话头像、人物画像、记忆页、总览/人设等出现头像的位置）统一显示为圆形，而不是方形。

## 实现

1. `aureus/web/static/index.html` 与 `aureus/web/static/*.js`：所有头像容器与 `img` 加 `border-radius: 50%`、`object-fit: cover`，保持现有尺寸与位置。
2. 没有图片时的像素占位头像同样裁成圆形（或保持像素方块？按统一圆形处理，占位图标不变）。
3. 学习工作台在 Shadow DOM 内，若其页面也有头像，在 `frontend/maibot-learning` 的主题样式里同样处理（只改样式，不改组件逻辑）。
4. 不改变头像加载、缓存与权限逻辑；不产生布局抖动。

## 验收

- 各页面头像均为圆形；占位头像同样圆形；尺寸与对齐不变；深浅主题与窄屏正常；工作台内头像（如有）也统一。
