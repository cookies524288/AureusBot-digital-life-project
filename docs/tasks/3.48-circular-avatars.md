# 3.48 所有头像改为圆形

状态：待评审
设计：维护者 2026-11-26 指令

## 目标

项目网页里的所有头像（会话消息头像、平台会话头像、人物画像、记忆页、总览/人设等出现头像的位置）统一显示为圆形，而不是方形。

## 实现

1. `aureus/web/static/index.html` 与 `aureus/web/static/*.js`：所有头像容器与 `img` 加 `border-radius: 50%`、`object-fit: cover`，保持现有尺寸与位置。
2. 没有图片时的像素占位头像同样裁成圆形（或保持像素方块？按统一圆形处理，占位图标不变）。
3. 学习工作台在 Shadow DOM 内，若其页面也有头像，在 `frontend/maibot-learning` 的主题样式里同样处理（只改样式，不改组件逻辑）。
4. 不改变头像加载、缓存与权限逻辑；不产生布局抖动。

## 验收

- 各页面头像均为圆形；占位头像同样圆形；尺寸与对齐不变；深浅主题与窄屏正常；工作台内头像（如有）也统一。

## 前端实测（2026-11-26）

实现：主页面目前只有平台会话的头像容器 `.inbox-avatar`（会话消息头像和输入中气泡共用
`inboxAvatarPlaceholder()`）。给容器加 `border-radius:50%`、`overflow:hidden`，给内部
`img` 也加 `border-radius:50%`，图片继续 `object-fit:cover`，28×28 尺寸和位置不变。
人物画像、长期记忆、总览、人设页没有头像元素，未改；学习工作台内没有头像组件（源码和
构建产物里只有 `avatarSaved` 等文案，没有头像 DOM），因此不需要改
`frontend/maibot-learning`，也没有重建产物。

- 主页面头像：用 4 条伪造平台消息渲染，4 个 `.inbox-avatar` 的计算样式均为
  `border-radius:50%`、`overflow:hidden`；有图头像的 `img` 为 `object-fit:cover`，
  圆形裁剪正常。截图 `E:/Temp/ui-shots/343-10-inbox-light.png`。
- 占位头像：无发送者的消息仍显示像素人物图标，容器同样 `border-radius:50%`；截图中
  最后一个头像可见。`343-10-inbox-light.png`。
- 窄屏与主题：深色 `E:/Temp/ui-shots/343-08-inbox-dark.png`，390×700
  `343-09-inbox-narrow.png`；头像尺寸不变、无布局抖动。Console `exceptions=[]`、`errors=[]`。
- 环境偏差：假器官实例没有真实 QQ 头像，用伪造消息和返回 PNG 的假 `fetch` 验证；原 18770
  和正式 28976 未改动。按维护者要求未跑 pytest。
