# 3.23 学习页左侧留白，导航展开时不挡操作

状态：待实现
设计：维护者 2026-11-25 指令；与 D122 的学习页内联工作台配套

## 问题

学习页为了内联工作台把 `#page-learning` 的 `padding` 设成了 0；左侧导航是绝对定位、悬停或键盘聚焦时从 56px 展开到 224px，会盖住工作台左侧的页签和操作。

## 目标

学习页内容始终避开导航：导航收起时只留出收起宽度，展开时内容平滑右移，不遮挡任何可操作控件。

## 实现

1. `#page-learning` 加左内边距，默认等于 `var(--nav-w)`（收起宽度），并加过渡。
2. 导航悬停或键盘聚焦时（`nav.side:hover`、`nav.side:has(:focus-visible)`、`.nav-trigger:hover` 的现有触发条件），学习页左内边距过渡到 `var(--nav-open)`；导航收起后恢复。
3. 学习页内部的宿主宽度随内边距自适应，不出现横向滚动；工作台内部布局不变。
4. 窄屏（≤820px）保持现有底部导航布局，不加左内边距。
5. 如果长期记忆页也做成全宽布局，同样处理；本次至少保证学习页。

## 验收

- 导航收起时学习页无多余大片留白；悬停展开时内容右移、页签与按钮不被遮挡；移开后恢复；过渡平滑无跳动；窄屏正常；深浅主题正常。
