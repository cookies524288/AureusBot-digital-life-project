## 目标和验收

1. `ModelConfig` 新增：`enabled: bool = True`、`price_periods`（列表，每项含本地开始/结束时间与输入/输出/缓存价格，校验格式与重叠）、`thinking: bool = False`、`web_search: bool = False`、`extra_params: dict[str, Any] = {}`（值允许 JSON 标量/对象/数组，限制大小）。
2. 停用模型不进入器官路由；器官绑定的模型全部停用时，该器官调用返回明确错误。
3. 适配器：`thinking` 为 true 时请求写入 `thinking: {"type": "enabled"}`；`extra_params` 合并进请求（显式字段优先）；`web_search` 仅对支持的协议加入原生搜索工具，其它协议忽略并在日志说明一次。
4. 计费按请求时刻所在本地时段取 `price_periods`，未命中用默认价格；账本记录使用的价格来源不影响字段。
5. `/api/models` 读写新字段并校验；旧 models.toml 照常读取（缺省值）。
6. 不真实调用模型；测试用假客户端与假时钟。

## 行为细则和边界情况

1. `price_periods` 时段按本地时间、左闭右开；重叠或顺序错误直接报错；最多 12 段。
2. `extra_params` 不允许覆盖 `model/messages/tools/stream` 等核心键；冲突时显式字段优先并记录一次 warning。
3. `web_search` 只对 `openai_responses` 协议加 `{"type": "web_search"}`；其它协议忽略。
4. 停用模型的绑定不删除，只跳过；重新启用即恢复。
5. 不改配置文件名与结构；旧配置缺新字段用默认值。
