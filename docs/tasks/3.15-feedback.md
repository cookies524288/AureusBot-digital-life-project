# 3.15 · 判断器官与自我监控反馈

状态：待实现。对应[台账](3.15.md)第 15 项；设计依据 D5、D41、D68–69、D73、D91、D103。先读[生理证据与既有校准](3.8.md)、`aureus/heartbeat/{conversation,context,judging,empathy}.py`、`aureus/core/cognitive_layer.py`、`aureus/web/{config_files,config_api}.py`。

## 已核对的基线

- `_conversation_job` 通过 `build_judge_context(identity)` 只给判断器两层人格；`_judge_emotion` 返回有界且校验过的 `Judgment`，不产生可执行指令。`_apply_hormones` 已把本轮合格触发与现有读数合成调节，更新规划/回复上下文、长度等策略；正式写入在心跳收回结果后进行。`CognitiveObserver` 的预算、激素与反馈置信度是另外一条只读观察路径。**有观察页不代表 judge 实际收到了这些状态。**
- 真正有生理动力学依据的是 `cortisol.half_life_seconds=3960`：Weitzman 等从小样本的内源性血浆脉冲估算平均 66 分钟，[原论文](https://doi.org/10.1210/jcem-33-1-14)。现有昼夜相位、上升过程、行为门槛的依据及局限已逐项列于 3.8，不重复推算。
- `anger`、`joy`、`hurt`、`surprise` 是软件情绪通道，不是四种分子。[Verduyn 与 Lavrijsen](https://doi.org/10.1007/s11031-014-9445-y)比较 27 种自报情绪历时：悲伤在样本中最长，惊讶属于短组；事件重要性和反刍也相关。研究没有测激素清除率，不能从中推出这四个聊天通道的秒数，低落也不等于研究里的全部悲伤事件。当前 600/900/1800/180 秒只作交互时间尺度的工程默认；6 小时心情是较慢的反馈整合，不是血浆参数。不把未经标定的数改名为人体测量值。

## 两个独立小步

1. **判断读状态，核心算影响**。在真实 judge 请求的人格背景后给出「判断前的自身状态」：只取同一轮正式开启的、允许给当前来源的身体读数、情绪和心情，区分「自己的状态」和「对方的证据」。不把私聊叙事、其它人的名字、原始反馈或未核实的自由文字升级为系统指令。保留旧 `Judgment` 结构；本轮判断经过既有代码算出调节后，以可核对的状态/行动摘要供 planner 和被显式调用的 replyer 使用。利用现有状态组装，不复制造血逻辑，不额外调用模型，不增持久状态。`judge.state_context_enabled` 独立开关，默认开；关闭回到原 judge 背景，原行为安全闸门及已有下游调节不受影响。扮演模式、无来源、已关闭的信号不伪造或回带。Prompt 管理中预览所用的合成材料及字段也要同步。
2. **固定网页不能调的数值**。维持整节 `cortisol` 的既有只读边界；`hormones` 中所有非开关的调节参数（半衰期、增益、门槛、窗口、次数），以及 `mood.half_life_seconds` 在网页和 Web 写接口均只读。各原有独立开关保持既有权限；不把记忆遗忘等其它同名字段一并锁住。使用同一服务端字段集合生成只读展示、拒写规则和总重置排除列表。普通、点路径、同值、混合请求、逐项恢复均不得绕过；被拒不应修改磁盘任何字节。显示开发默认和来源类别。已有本机 TOML 的覆盖仍按原约定读取，不替用户改写或迁移数值。

## 自检

- [ ] 比较同一组合成事件、时钟与输入在开/关下的实际 judge、planner、replyer 请求；私聊/群聊不串来源。合法新判断影响本轮策略，失败和非法值不会凭空增加触发，临时共情不重复累计。
- [ ] 相同的运行配置在网页 schema、单改、混合改、恢复和总重置得到一致的保护，允许的开关仍可独立关闭；原 TOML 覆盖保留。

不做：添加未经验证的新递质、将人类研究结果冒充逐人诊断、让模型写浓度、真实收费调用或修改正式配置。
