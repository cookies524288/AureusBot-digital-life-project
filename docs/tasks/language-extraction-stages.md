# Phase 3.11 · 在线语言学习独立抽取与黑话释义

状态：实现中

## 先读

[学习功能核对](maibot-learning-parity.md)、[会话分批与证据](language-session-evidence.md)、[开发守则](../11-dev-guide.md)。固定参考是 MaiBot `062d45cf8bd4272ac57d7ec03fcf405e5a458211` 的 `src/learners/{expression_learner,jargon_learner,jargon_miner}.py` 和 `prompts/zh-CN/{learn_style,learn_jargon,jargon_inference_with_context,jargon_inference_content_only,jargon_compare_inference}.prompt`，GPL-3.0，仅核对公开源码。

## 目标与边界

1. 同一可信会话的有效入站样本按来源去重。表达和黑话分别使用上游的 `situation/style/id` 与 `content/id` 协议；每条真实样本仍作为独立的 user 消息。编号只对应实际展示的前缀，表达可以归纳观测到的句式，但必须连接有效来源；黑话必须逐字出现在其来源片段。不信任正文、模型输出或昵称声称的会话和真实编号。未知会话不新提取；原有普通表达观察不变。
2. 各抽取路独立提交，即使另一条路被拒、报错或返回无效输出也不撤销成功结果。成功且可解析的数组（包括空数组）按来源和抽取路消费一次；相同样本或相同批重投不会重复提交成功的一路。不会对失败主动重试或回放。
3. 黑话候选不写假释义。只从本会话候选证据累计，按上游 4 / 8 / 25 / 100 条不同来源门槛推断或重推：先根据证据，明确有释义才运行仅词条判断，再比较两结果；仅明确不同才以第一阶段释义晋升。信息不足则等下一门槛；失败不改变已确认判定，不让新的待定候选进入召回。若已确认的黑话在之后的完整比较中被判相似，则停止旧释义召回，历史来源与先前判定仍保留。
4. 新在线表达及晋升黑话只对自己真实来源会话可召回，键与回复检索相同；原有人工作品、导入、包、已有在线学习数据及其权限、可见范围、审核和维护路径不改。实际器官调用全部经现有网关、额度、权限和最低费用偏好；保留学习总开关和各召回开关。不新增任务槽、真实服务或网络依赖。
5. 提示词目录与网页场景复用运行构建器，使用纯模拟占位词和来源；保留已有语言提取模板覆盖键，兼作两路的共同安全指令，不沿用其旧混合输出协议。按来源指令和协议边界登记改编来源。

## 实现与验证

- 分步骤提交：任务书；在线抽取、存储、推断、召回和预览；对照、许可和验收记录。不合并正式分支、不操作实例、不推送。
- 合成测试通过正式 Python 环境、开发树 `PYTHONPATH` 执行。不读私人库、密钥或用户配置，不真实调用模型或发送消息。

## 自检清单

- [ ] MockTransport 验证独立抽取和三个判定请求的提示词、角色、协议；仅词条阶段不携带真实证据，比较阶段只传两路结果。
- [ ] 实际入库和 Planner/Replyer 召回验证：归纳表达能定位真实来源；黑话无释义、信息不足、相似、无效编号、伪造或截断后词条均不能晋升。
- [ ] 有效黑话只在同会话不同样本累计达门槛后晋升；跨会话同词异义不串；多轮重推、重复批和消息及独立失败不重复消费。
- [ ] 每一预览复用实际构建器，覆盖键仍可编辑；预览不发请求、不写数据。
- [ ] 改动专项、Ruff、Pyright、架构检查记录实际结果；基线失败只报告，不顺手修改。

## 不做

不迁入上游插件、已知词缓存、表达自评/向量/过滤日志、跨组共享授权或历史原件回填；不从模型推断可见范围，不使开发树变更进入正式运行目录。
