# 3.13 · 资源页数据和记忆事件流

状态：实现中

## 路线与验收

1. 长期记忆的记忆流显示记忆和人物资料的关键变动，区分画像创建、资料合并、关系冻结等实际发生的事件。展示类型、发生时间及摘要，可按会话、事件类型、日期筛选。检查已有迁入记录与本地事件。普通聊天及一般记忆原文保留在各自页面。
2. 主页面切换的淡入时长改为原值除以 1.3。子菜单切换直接更新内容。检查从导航点击与从地址直接进入的表现，保留减少动画偏好。
3. 沿正式入口追查学习和长期记忆空页，核对启动器、数据根目录、迁移目标表、网页查询及渲染。以已迁入的 Aureus 库的结构和汇总计数检验，不读用户对话及 MaiBot 原库。以临时库验证修复对既有数据生效，重复启动或读取不增加重复记录。

4. 模型库「视觉」列使用直角方形指示灯。开启时绿色实心，关闭时空心；复核两种状态及原有提示。
5. 登录后添加、编辑模型供应商可直接保存，表单和保存接口同步取消此次操作的二次密码。验证新增及编辑都能保存并读回；继续沿用原有会话、同源及其他操作的权限规则。
6. 弹窗点击遮罩空白处等同于关闭或取消。右上角关闭按钮可见内容统一为像素 ×，保留读屏名称和键盘操作。
7. 在添加和编辑模型的供应商模型列表提供不区分大小写的搜索，核对筛选、选择、手动输入、刷新和切换供应商。

仅运行对应专项。各子会话限定路径提交，主会话汇总复审及交接。
