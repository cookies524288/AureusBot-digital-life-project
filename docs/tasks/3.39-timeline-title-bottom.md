# 3.39 时间线标题固定在页面顶部

状态：待实现（2026-11-26 维护者改为「标题固定顶部」，不再移到底部）
设计：维护者 2026-11-26 指令（修订）

## 目标

时间线页面的标题区域在页面滚动时保持固定在顶部，始终可见；不再把标题移到底部。

## 实现

1. `aureus/web/static/index.html` 的 `#page-timeline`：标题「时间线」与刷新按钮放进粘性头部（`position: sticky; top: 0`），滚动列表时保持可见；必要时加背景与边框避免内容透出。
2. 底部仍保留 3.20 的筛选工具条与滚动摘要顺序；不要重复标题。
3. 粘性头部高度与页面内边距协调，滚动到顶部/底部都不遮挡首尾内容。
4. 窄屏与深浅主题正常；不改变筛选、列表、详情与滚动行为。

## 验收

- 时间线标题在滚动时固定可见；首尾内容不被遮挡；窄屏与主题正常；刷新按钮可用；不出现重复标题。
