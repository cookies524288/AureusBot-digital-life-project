# 3.39 时间线标题移到底部并调整排版

状态：待实现
设计：维护者 2026-11-26 指令

## 目标

时间线页面的标题移到底部，页面整体排版美观、与其它页面协调。

## 实现

1. `aureus/web/static/index.html` 的 `#page-timeline`：把标题「时间线」从顶部移到底部区域（与筛选工具条、滚动摘要同处底部，顺序自行排布得美观）。
2. 顶部不再保留标题与「刷新」按钮？「刷新」保留在顶部或移到底部，按美观决定；刷新功能不变。
3. 调整底部各块间距与对齐，避免拥挤；不改变列表、详情、筛选与滚动行为。

## 验收

- 标题在底部可见且与底部工具条/摘要排布协调；顶部内容不突兀；刷新可用；窄屏与深浅主题正常。
