# 路线图 3.65：聊天基本功与 MaiBot 插件效果

状态：实现中。设计：D147；选择依据、每项验收场景和上游源码见[对照表](../maibot-chat-parity-plan.md)。编号沿用对照表，不随优先级重排。只登记有证据的完成项，真实 QQ 验收与本地模拟分开。

## 目标与接口

1. **会话与原件**：01 选回复目标、02 点名上下文和引用唤醒、03 解引用、04 熟人和发言者归属、05 实际投递历史、06 跨轮媒体。用本轮候选的稳定消息键选人，未给目标兼容单消息；不可伪造编号、换会话或借引用升级权限。只读已获准的原件，摘要有真实来源。
2. **QQ 动作**：07 正文后补图、08 单图回复、09 斗图或复读、10 原生表情、11 贴表情、12 群内主动戳、13 被戳回应、14 撤回自己指定消息、15 撤回通知/可选跟撤、16 原生 @。模型只提出动作，运行时验证目标，通道依 SnowLuma 返回值记实；过期、重复、平台拒绝不产生虚构成功。跟撤独立开关，不另连旁路。一个动作只有一个出站路径。
3. **节奏与媒体**：17 定时回看、18 有限续话、19 按位置重发同会话旧图、20 转发与卡片、21 普通动图/视频/音频/文档、22 正文/分段/纠错。17–18 用注入时钟，不循环自启；19、21、28 区分收到、理解和允许发送。无法提取不冒充看过；22 不破坏代码、URL 与引用，纠错可复用 14，刻意制造错字不默认开启。
4. **插件能力**：24 查询实际群名单、25 通用梗词典（未知就说未知）、26 提醒的建立/查询/取消/到期判断、27 主人的限时跨会话叮嘱、28 受托发送指定文件/普通图片。24 不给普通成员整份名单。26 默认原会话，跨流须主人及获准目标；27 一次有效发言后消费，未发不算；28 只在获准的素材范围内送回授权会话，拒绝任意文件路径。

## 子步骤与自检

按上述编号逐项验收；独立的协议和媒体解析可与决策实现并行，接口接入后串行核对。每次验证使用合成数据、项目时钟、模拟通道/器官；不把工具注册、单独的解析测试或模型表示成功当成真实投递。

| 范围 | 要记录的实证 |
|---|---|
| 01–06 | 多人插话后的真实目标、引用背景与发言者、成功/失败分段、隔轮媒体问答 |
| 07–16 | 真实出站段和动作参数、失败/重复/撤回/失权时发出 0 次、群私分别测试 |
| 17–22 | 假时钟等待与取消、可渲染原图、转发说话人、媒体内容来源、标记代码与链接不变 |
| 24–28 | 群名单授权、已知/未知梗、到期只处理一次、非主人叮嘱被拒、授权文件与拒绝路径 |

## 不做与协作
