# 3.15 · 可携带的长期记忆包

状态：容器互通和选源管理已合入，未作正式库验收。对应[管理工作台](3.15-resource-console.md)。先读固定版 `bundle_admin_service.py` 的成员规范和[实现与验收证据](evidence/3.15-bundles.md)。

1. **生成 v1 知识包／完整包。** 网页在导出前选择内容层级与可信来源范围，显示实际闭包及不能输出的对象。full 写 `state.json`，只保留已授权且可重建的段落、实体、关系、事实、画像、情景等及必要键；不从数据库备份或原件正文拼凑。旧值、失效、撤销以及没有导出权的对象不参与。生成的清单、规范化摘要、安装 ID 和引用与固定版吻合；不可导出的持久资料明确说明，不将部分结果称为全库备份。旧 v1 兼容性不变。
2. **v2 图片。** 按上游 `images.json` 的资产/出现/观察/链接及 `images/assets/<内容摘要>.<格式>` 处理，按内容校验字节，并检查所有引用确实属于同一获准闭包。预检报告将导入或跳过的成员与原因，不显示外部绝对路径。安装持久所有权，卸载不伤其它所有者，不能凭附件或包反查原始聊天。按上游规范计算包含图片语义的 `content_digest`，另验每个成员的 SHA-256；没有获准原件就不导出它。
3. **可选向量。** `vectors/{paragraphs,graph,images}.npz` 只在内容键、维度、模型/算法与已配置空间完全相符时安装到真实读侧；无匹配空间在预检明确提示跳过后允许仅导入知识。不允许 pickle、对象数组、非有限数值、越界尺寸、不在清单的路径或解压到调用者指定位置。限制外层及嵌套压缩的展开字节数，读取头信息后再分配。分别证明固定版样本可读、本地生成包与上游预检兼容和卸载后无残余召回。

自检仅用构造的包和合成索引，涵盖损坏校验、重复安装、无导出权、同一媒体有其它所有者、不同指纹和不兼容的可选成员。分步合入，不改写真实库、资产或导出目录。
