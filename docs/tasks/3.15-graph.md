# 3.15 · 可操作的关系图与独立展示授权

状态：待实现。对应第 4 项；先读 [固定版对照](3.15-parity.md)、[图谱授权边界](supplemental.md#memory-graph-web)、`aureus/{memory/graph_query,web/memory_graph_api}.py`、`aureus/web/static/resource-management.js`。Lieflat Charts 已安装；按 `SKILL.md` 与 `catalog.md` 的 B2（`templates/big-force.html`）学习节点定位、邻接聚焦和详情，不复制非商业许可的模板、布局代码、示例数据或美术素材。

## 子步骤

1. **可视化**：在长期记忆关系图页实现真实可交互的网络，不以记录卡列表代替图。使用原生 SVG 和本项目主题，以不可变完整 `MemorySource` 为节点键，边保留方向、谓词和各自的详情。每个分页切片只画服务端当前授权的实体/关系及已返回的端点，不补造跨页边。提供稳定布局、鼠标/键盘选点、邻接高亮、缩放/复位、聚焦到一跳、搜索和独立详情；窄屏仍可操作，保留无图的等价列表与页码输入。无授权、未命中、服务错误和加载分别诚实展示。切页、改筛选、退出、撤权、用户会话变化时废弃旧图与详情（迟到响应也不可复活）。不加载 CDN/遥测；姓名、谓词和证据一律按文本呈现。只有覆盖当前页就明说，不写成全库关系数。
2. **正式授权来源**：目前 `register_memory_graph_routes` 有 `GraphGrants` 接口，但正式组装没有传入。保留默认空；认证登录、能搜到记忆、安装知识包、内部召回权限都不等于授权展示。向维护者提供独立的授予/撤回操作，复验密码。只能选择服务端核定的已发布来源批次，使用可信来源键快照（明确区分实体、关系和证据）；批次内容后来变化或新加项不能借旧授权自动展示。未授权列表只显示可管理的来源标识，不预览图内容。查询时重新取权，撤回后总数、布局、详情和一跳均不可泄漏旧图。不能把网址参数、浏览器提交的节点键或任意数据库扫描当作图权限。关闭展示权限不得删除资料或关闭独立的内部召回。

## 自检

- [ ] 两个同名实体不合并；同一有向端点的多个谓词均可检查；孤立节点和自环不消失；空授权不绘制示范数据。
- [ ] 拖选或键盘定位后能准确打开已有详情、可返回全图；快速翻页和切标签时旧响应不会显示。搜索与详情不扩大授权。
- [ ] 授权后可见、撤回后消失；证据独立授权，来源变化不自动扩权；未实际授予时不开放任何真实图数据。

不做：把正式数据导入演示图、推断两个人是同一人、复制技能资产、修改旧记忆资料或替维护者授予权限。按 D104 只提醒重启验收。
