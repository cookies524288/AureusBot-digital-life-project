# 3.10 · 回复器内部再审

状态：完成

有规划建议的回复请求附上固定的再审协议、规划理由及一次性标记。回复器驳回时，心跳只把理由送回规划器一次。规划器明确决定沉默、重规划不可用、标记不完整或再次驳回时，安静结束本轮。只有最终获准的正常回复才进入分段发送、时间线和规划副作用。

管理页展示原文及标记的示例替换。再审沿用当前会话的消息批次、模型档位和安全网关，并受本轮重试限额约束。
