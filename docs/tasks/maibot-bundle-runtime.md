# 路线图 3.5 后续：MaiBot 记忆包

状态：待评审
设计：[D99/D100](../10-decisions.md)、[兼容性核对](maibot-memory-parity.md)。先读固定版 `062d45c` 内置 A_Memorix 2.0.0 的 `memory_bundle_format.md`、`bundle_admin_service.py`，及本地 `aureus/memory/history.py` 和网页传输入口。

## 目标与边界
- 长期记忆 → 导入导出：保留 JSONL；另支持 `.amembundle` 的预检、合并、仅空记忆库的完整包恢复、安装记录、可逆卸载及恢复。
- 采用上游 ZIP 格式、SHA-256 清单及内容摘要。仅接入能写入真实记忆存储的成员；不忽略未支持成员。会话保留为来源元数据，不限制召回。
- 安装和归属事务提交。包独占资料卸载后不召回，但不删原件、证据或时间线；共享包资料、原有资料和自学资料不受影响。恢复不覆盖单独的人工设置。
- 先跑合成包最小专项；不读正式库、不调用网络、不合入主线、不重启。

## 自检清单
- [x] `test_maibot_bundle_installs_in_recall_and_uninstalls_only_exclusive_material`：合成包接入真实网页接口与索引，重复和共享安装、卸载、恢复、下载均实跑。
- [x] `test_maibot_full_bundle_requires_empty_store_and_rejects_unsupported_members`：兼容完整包仅空库可恢复，情景关联可读，不支持或校验失败的包不写入。

## 尚未等价的部分
- 图片 v2、向量、关系回收站及其他未接入的 ZIP 扩展明确拒绝。支持的原始字段随包留存和下载；运行不恢复上游关系强化、冻结计时、有效权重、图向量或任务缓存。
- 同一内容的知识段落可跨包共享；完整包按语义快照保留独立原 ID。可以重新下载某次安装的原包，或用本机可用记忆段落生成 v1 知识包；尚不能从本机生成完整包或按导入批次选择范围，原 JSONL 保留。
- 不支持按聊天流装到不同库或重写标识；聊天来源保留，遵循 D100。导入的图数据沿用现有独立授权，不自动开放网页图谱。

## 第二步
- 事实、事实证据和转换、外部引用接到记忆原件，保留有效期与历史状态。画像、正文覆盖、别名覆盖和上游证据键接到人际目录；只用已核实且无歧义的迁入人物键，不凭姓名或包内账号建档，未匹配人物的画像保留为待解析。
- 导出本机当前可用段落及关联为标准知识包，不把 JSONL 包改名替代。合成网页专项 9 项通过，包括人物召回、卸载恢复、事实证据和导出包回读。
