## 接口

### 反馈子系统（`aureus/feedback/simulation.py`）

- `brier_score(attempts: Sequence[SimulatedAttempt]) -> float`：每次 `(expected - (1 if succeeded else 0)) ** 2` 的平均。空序列抛 `ValueError`（和 `expected_calibration_error` 对空序列的处理保持一致；先看它现在怎么做，照它来）。
- `calibration_bins(attempts) -> list[CalibrationBin]`：把 `expected_calibration_error` 里分箱的那段抽出来共用（ECE 改成调用它，行为不变），`CalibrationBin` 是冻结数据类：`lower`、`upper`、`count`、`mean_expected`、`success_rate`。空箱不返回。

### 实验台：数据（`aureus/lab/experiment.py`）

```python
MetricValue = int | float | bool | str

@dataclass(frozen=True)
class Table:
    """一张表，写成 CSV。"""
    name: str                       # 文件名（不带 .csv），只能是小写字母、数字、下划线
    columns: tuple[str, ...]
    rows: tuple[tuple[MetricValue, ...], ...]

@dataclass(frozen=True)
class Series:
    label: str                      # 图例上的文字
    x: tuple[float, ...]
    y: tuple[float, ...]

@dataclass(frozen=True)
class Chart:
    """一张折线图，画成 PNG。"""
    name: str                       # 文件名（不带 .png），规则同 Table.name
    title: str
    x_label: str
    y_label: str
    series: tuple[Series, ...]

@dataclass(frozen=True)
class ExperimentResult:
    metrics: Mapping[str, MetricValue]   # 写进 metrics.json；E2 这种分组的指标用「组名.指标名」做键
    tables: tuple[Table, ...]
    charts: tuple[Chart, ...]

@dataclass(frozen=True)
class Experiment:
    name: str                       # 命令行里的名字，如 "calibration"
    code: str                       # 12 号文档里的编号，如 "E4"
    title: str                      # 中文标题
    parameters: Mapping[str, MetricValue]   # 默认参数，原样写进 config.json
    run: Callable[[Mapping[str, MetricValue], int, Path], Awaitable[ExperimentResult]]
    # run(参数, 种子, 运行目录)：实验用的数据库建在运行目录里
```

所有图都是折线图（校准图把「理想对角线」也画成一条线）。不做柱状图、散点图等别的种类。

### 实验台：输出（`aureus/lab/output.py`）

- `RUN_DIRECTORY_FORMAT = "%Y%m%d-%H%M%S"`；`KEEP_RUNS = 20`（D82 第 5 条）。
- `create_run_directory(experiments_dir: Path, name: str, now: datetime) -> Path`：建 `experiments_dir/name/<now 按格式>`；同名已存在就加 `-2`、`-3`……（一秒内跑两次）。
- `write_config(run_dir, experiment, seed, version)`、`write_metrics(run_dir, metrics)`、`write_tables(run_dir, tables)`：JSON 用 `ensure_ascii=False, indent=2, sort_keys=True`，UTF-8，结尾换行；CSV 用标准库 `csv`，UTF-8 带 BOM（`utf-8-sig`，用户双击用 Excel 打开不乱码）。
- `prune_runs(experiment_dir: Path, keep: int = KEEP_RUNS) -> list[Path]`：只看名字符合 `^\d{8}-\d{6}(-\d+)?$` 的子目录，按名字排序保留最后 `keep` 个，删掉其余的（`shutil.rmtree`），返回删掉的路径。别的文件和目录不碰。

### 实验台：画图（`aureus/lab/charts.py`）

- `matplotlib_installed() -> bool`：`importlib.util.find_spec("matplotlib") is not None`。
- `draw_charts(run_dir, charts) -> list[Path]`：函数内部才 `import matplotlib`，先 `matplotlib.use("Agg")`；每张图一个 `Figure`（用 `matplotlib.figure.Figure`，不用 `pyplot`，避免全局状态），存 PNG 后关掉。调用方先判断装没装。
- 中文标题：设 `font.sans-serif` 为 `["Microsoft YaHei", "SimHei", "Noto Sans CJK SC", "DejaVu Sans"]`，找不到字体时 matplotlib 只出警告，不算错误。

### 实验台：运行（`aureus/lab/runner.py`）

```python
@dataclass(frozen=True)
class RunReport:
    run_dir: Path
    metrics: Mapping[str, MetricValue]
    charts_drawn: bool            # False 就是没装 matplotlib
    pruned: int                   # 这次删掉了几个旧的运行目录

async def run_experiment(
    experiment: Experiment, seed: int, experiments_dir: Path, clock: Clock
) -> RunReport:
```

顺序：用 `clock.now()` 建运行目录 → 写 config.json → `await experiment.run(...)` → 写 metrics.json 和 CSV → 装了 matplotlib 就画图 → `prune_runs`。实验抛异常时运行目录留着（里面有 config.json，方便查），异常往上抛给命令；不删别的运行目录。

### 实验台：登记（`aureus/lab/registry.py`）

`EXPERIMENTS: Mapping[str, Experiment]`，键是 `name`，现在只有 `calibration` 和 `energy`，按这个顺序。

### CLI（`aureus/cli/lab_command.py`）

- `aureus lab list`：每行「名字  编号  标题」。
- `aureus lab run 名字 [--seed 整数]`：种子默认 0，可以是 0 或正整数。用 `SystemClock` 建运行目录；运行目录 = `AureusPaths(...).experiments_dir`（数据根目录怎么来照 monitor 命令）。数据根目录不存在时照样能跑（实验不需要初始化过的家），按需建 `experiments/`。
- 跑完打印：运行目录路径，每个指标一行「指标名：值」（浮点保留 4 位小数），以及「已画图 N 张」或 `NOT_INSTALLED_MESSAGE = "没装 matplotlib，这次只输出了指标和表格，没画图。装法：uv sync --extra lab"`；删了旧运行时打印「删掉了 N 个更早的运行结果（每个实验只留最近 20 次）」。返回 `EXIT_OK`。
- 名字不在登记表里：打印「没有叫 X 的实验，可用的有：calibration、energy」，返回 `EXIT_FAILURE`。实验抛异常：打印「实验失败：<异常文字>，运行目录：<路径>」，返回 `EXIT_FAILURE`，不打印堆栈。
- 不拿单实例锁，不读 aureus.toml、models.toml、identity.toml 和密钥。

### E4 置信度校准（`aureus/lab/calibration.py`）

- `name="calibration"`，`code="E4"`，`title="置信度校准：反馈得来的自信准不准"`。
- 默认参数：`rate_hard=0.3`、`rate_mid=0.7`、`rate_easy=0.9`、`rounds=200`、`window_rounds=20`。三类任务名就是 `hard`、`mid`、`easy`。
- 组装：`FeedbackStore(run_dir / "experiment.db", FeedbackConfig(), ManualClock(LAB_START))`，`open()` 后调 `run_simulation(store, tasks, rounds, seed)`，`finally` 里 `close()`。`LAB_START` 是 D82 第 4 条的固定起点，放在 `aureus/lab/experiment.py`，两个实验共用。
- 对照组：同一批 `SimulatedAttempt` 的结果，`expected` 一律换成反馈的先验 `PRIOR_CONFIDENCE`（从 feedback 导入，不要写 0.5）。这就是「不学习、一直说一半把握」。大模型自评要花钱，不做（D82 第 3 条）。
- 指标：`feedback.ece`、`feedback.brier`、`prior.ece`、`prior.brier`、`attempts`（总次数）。
- 表 `convergence`：列 `round_end, feedback_ece, prior_ece`。每 `window_rounds` 轮一行，算的是这个窗口内的那些行动（不是累计），这样才看得出越往后越准。`rounds` 不能被 `window_rounds` 整除时，最后不满的一段也算一行。
- 表 `reliability`：列 `lower, upper, count, mean_expected, success_rate`，来自 `calibration_bins`，只算反馈一侧。
- 图 `ece_by_round`：横轴「轮数」，纵轴「ECE」，两条线：反馈、先验对照。图 `reliability`：横轴「说的把握」，纵轴「实际成功率」，两条线：理想（(0,0) 到 (1,1)）、反馈（各箱的 mean_expected 对 success_rate）。

### E2 精力调节（`aureus/lab/energy.py`）

- `name="energy"`，`code="E2"`，`title="精力调节：开、关精力信号各跑一个月"`。
- 默认参数：`monthly_token_limit=300_000`、`days=30`、`tokens_per_call=500`、`user_messages_min=1`、`user_messages_max=3`、`optional_wishes_per_day=40`。用户消息少是有意的：精力只给用户留了每日额度的 15%（`user_reserve_fraction`），这样的负载正好落在留出的那部分里；可选的事想做的远多于额度，才看得出精力闸门在不在起作用。
- 模拟用户（规则脚本）：`build_schedule(params, seed) -> list[list[EventKind]]`，`EventKind` 是 StrEnum：`USER_MESSAGE`、`OPTIONAL_WISH`。用 `random.Random(seed)`，每天 `randint(user_messages_min, user_messages_max)` 条用户消息加 `optional_wishes_per_day` 件可选的事，`shuffle` 打乱。先生成整个月，开、关两次用同一份。
- 假器官 `TokenOrgan`：照 `tests/body/test_body.py`，每次报 `prompt_tokens = tokens_per_call * 4 // 5`、`completion_tokens = tokens_per_call - prompt_tokens`。`organ_id` 用 `"replyer"`。
- 每次运行（`energy_enabled` 为 True 一次、False 一次）在运行目录里各用一个数据库：`energy_on.db`、`energy_off.db`（E4 用 `experiment.db`）。组装照 `tests/body/test_body.py` 的 `Rig`：`ManualClock(LAB_START)`、`BudgetCalendar(UTC)`（日界线用默认的 4 点）、`Ledger`、`TimelineDatabase`、`Body(BodyConfig(energy_enabled=...), limit, ...)`、`SafetyGateway(..., SafetyConfig(monthly_token_limit=limit, runaway_guard_enabled=False), PermissionChecker(EmergencyStop(run_dir / "halt_on.json" 或 "halt_off.json", clock)), energy_gate=body)`。`finally` 里关掉账本和时间线。
- 时间：第 d 天（从 0 起）的事件从 `LAB_START + d 天 + 8 小时` 开始，每件之后拨 1 分钟。这样每一天都完整落在同一个预算日里（4 点日界线），整个月都在 11 月。
- 每件事：用户消息用 `CallPurpose.USER_REPLY`，可选的事用 `CallPurpose.OPTIONAL`，调 `gateway.call`。接住 `EnergyDepletedError` 和 `BudgetExceededError`：可选的事被拒就算没做；用户消息被拒就算没回上，这一天算断粮。别的异常不接，让它抛出去（实验失败）。
- 每天结束时用 `ledger.tokens_used_in_day(clock.now())` 读当天花费（指标从账本算，D15）。
- 指标（`on.` 和 `off.` 两组，各有这些）：`month_spend`、`overspent_days`、`starved_days`、`user_messages`、`user_response_rate`、`optional_done`。`overspent_days` 和 `starved_days` 的算法按 D82 第 8 条：第 d 天结束时累计花费 > `monthly_token_limit * (d + 1) / days` 算超支；当天有用户消息因为 `BudgetExceededError` 被拒算断粮。`user_response_rate` 是浮点数，没有用户消息时是 1.0。
- 表 `daily`：列 `day, on_spend, off_spend, on_cumulative, off_cumulative, even_pace`，`day` 从 1 起。
- 图 `daily_spend`：横轴「第几天」，纵轴「当天花费（token）」，两条线：开着精力、关掉精力。图 `cumulative_spend`：纵轴「累计花费（token）」，三条线：开着精力、关掉精力、均匀进度。

## 行为细则和边界情况

- 不读系统时间：实验里只用 `ManualClock`；运行目录名用命令传进来的 `SystemClock`。ruff 的 banned-api 会查。
- 可复现：`metrics.json` 只含指标，不含运行时刻、路径和版本（这些在 config.json）。浮点数原样写，不在写文件时四舍五入。
- 不碰它自己的数据：实验台的数据库都在运行目录里；测试要断言跑完后数据根目录里没有 `data/aureus.db`。
- 运行目录名重复时加后缀，不覆盖已有结果。
- `prune_runs` 只删本实验文件夹下符合格式的目录；手放进去的别的文件、别的实验的目录都不碰。
- 画图失败（装了 matplotlib 但出错）不吞掉：往上抛，命令按「实验失败」报告。指标和 CSV 已经先写好了，留在运行目录里。
- 日志：E2 一个月里安全网关每拒一次就记一条日志，关掉失控拦截时也记一条警告，一次运行有几千行。`run_experiment` 在调用实验期间把 `aureus` 日志器的级别临时调到 ERROR，结束后（含出错）恢复原级别。拒绝照样写进实验数据库的时间线，不影响指标。
- `--seed` 只收 0 和正整数（照 `positive_int` 的写法另写一个 `non_negative_int`，如果 cli 里已有就复用）。

  - 跑完后数据根目录里没有 `data/aureus.db`、没有 `config/` 下的文件被读或建（用一个空的 tmp 目录当数据根目录，跑完后只多了 `data/experiments/`）。

  - `aureus lab list` 输出两行，含 `calibration`、`E4`、`energy`、`E2`；

## 坑

- docs 里的文件多是 CRLF 换行，代码是 LF；改文档时保持原来的换行。全部 UTF-8。
- 完整检查要跑 4 到 5 分钟，别中途打断。
- matplotlib 第一次 import 会建字体缓存，很慢，而且会往用户目录写缓存：只在真正画图时才 import，测试里画图的用例能少就少（一个实验跑一次就够了，共用 fixture）。
- Windows 上 `shutil.rmtree` 删刚关掉的 SQLite 文件可能因为句柄没释放而失败：确保每个实验在 `finally` 里关掉数据库连接；测试里也别留着打开的连接。
- `Ledger`、`TimelineDatabase` 要先 `open()`；`SafetyGateway` 的月度上限和精力闸门读的是同一个账本，参数都照 `tests/body/test_body.py`。
- E2 的数字取决于精力闸门现在的算法（D56 的 85% 和 15%）。Claude 用一个临时脚本按本文档的组装方式试跑过默认参数、种子 0：开着月花费 298,000、超支 0 天、断粮 0 天、响应率 1.0；关着月花费 300,000、超支 29 天、断粮 16 天、响应率约 0.47。你的结果应该和这个一致或很接近。E4 也试跑过（种子 0）：反馈 ECE 0.0495、Brier 0.1867，先验对照 ECE 0.1283、Brier 0.25；第一个窗口 ECE 0.129，最后一个 0.054；种子 0 到 4 都满足验收。默认参数下验收第 6 条不成立时，不要改精力闸门，也不要自己改负载凑数：写进「待设计问题」，贴出实际指标，然后停下。
- 不要把测试里的 `TokenOrgan` 挪进 aureus 里给测试复用：实验台和测试各写各的，改测试文件不在这一步的范围。
