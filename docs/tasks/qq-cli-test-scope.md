## 改动一览与边界

旧用例在 `3198484` 独立复现：30 秒内收不到首条群回复。只读查询合成数据库，测试群消息 22 已进收件箱，私聊消息 21 未进入；群消息尚未进入时间线。普通群聊不立即唤醒心跳，原用例沿用 60 秒心跳间隔；夜间还会进一步放慢。共享子进程夹具推进的是收件箱的闲置时钟，不会唤醒心跳。

让本用例显式使用其他 QQ CLI 回归已使用的 1 秒心跳并关闭夜间休眠，保留收件箱逻辑及既有断言；不新增生产接口或配置项，也不延长测试超时。
