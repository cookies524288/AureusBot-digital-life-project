## 目标和验收

配置好嵌入模型后，索引自动、持续地建到完成，无需用户操作。

验收：

1. 文本嵌入可用且 `[indexing] auto_build_enabled=true` 时，心跳启动后台构建：表达索引覆盖所有已授权来源范围，表情描述缓存覆盖所有可发送表情；两者都按批推进，直到 `established == eligible`。
2. 图片嵌入可用时，回填已收到但未建索引的图片（按会话权限过滤），直到完成。
3. 构建期间心跳不阻塞；每批之后让出；急停、关闭、模型移除、来源撤权时立即停止，已建部分保留，不报错。
4. 预算耗尽或精力闸门拒绝时暂停，条件恢复后继续；不绕过安全网关。
5. 关闭总开关后不再自动构建，回到现有按需补建；配置范围校验，越界报错。
6. 器官面板统计在构建中显示部分完成，完成后显示完整；不新增对外字段。

## 行为细则和边界情况

1. 构建器是心跳持有的单一任务，不能与按需补建并发写同一索引；用现有锁或任务判忙跳过。
2. 每批只处理配置的条数，批间等待 `interval_seconds`；心跳 tick 不受影响。
3. 权限：只处理当前可见、已授权会话的数据；撤权后跳过，不重建。
4. 失败：单条失败记录并跳过，不中断整批；连续失败过多时暂停到下一轮（不新增无限重试）。
5. 模型切换：空间变化时丢弃不兼容向量（沿用现有 `discard_incompatible`），从新空间重建。
6. 不做：改变索引算法、改变召回、为长期记忆建全库索引、导入外部向量。
