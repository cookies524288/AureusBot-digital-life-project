# 长期记忆：保留关系图的结构化来源

状态：待实现

## 先读

Phase 3.11 长期记忆维护。先读 `docs/tasks/maibot-memory-parity.md`、`docs/13-references-and-migration.md`、`docs/14-user-data.md`，再核对 MaiBot 1.3.15 固定提交中 `metadata_schema.py` 与 `graph_admin_service.py` 对实体、关系方向、段落证据和删除状态的定义。只读公开代码，不访问已部署的库、暂存行、配置、日志或聊天。

## 目标与边界

建立可测试的结构化读取通路，供后续关系图搜索、边详情及证据展示使用。不得把两个名称之间的共现、改写后的正文、昵称碰撞或词间空格当成关系。已有只有正文的库保持可读，不重解释旧记录，不要求用户重新迁移正式数据。来源标识用于确定同一条记录，不代表浏览权限。上游字段无法消歧或不能确定授权时，不生成可见边。

## 子步骤

1. 从固定版本的公开定义和合成暂存行确认端点字段的真实语义，区分实体哈希、名称、谓词和段落引用。以完整来源键区分实例；不得仅以显示名称作为跨记录主键。记录查证位置。
2. 在现有记忆子系统内以最小改动保留这些独立字段及来源状态。提供非推测的只读查询，调用者必须明确给出获准读取的原件范围；先应用范围、删除及停用规则，再做聚合或计数。未解析或不可见的端点不进入结果。段落证据与语义边分开；不把边数、置信度和证据数混作一项。
3. 用新建的合成库覆盖迁移、关闭再打开、重复发布与旧版兼容。确认查询不会增删改原件、写时间线或改变召回。不得为了测试在正式库中创建表、重建索引或运行迁移工具。

## 自检清单

- [ ] 两个实例中同名实体不会合并；主体、谓词或客体含空格的不同三元组不会因正文相同而混淆。
- [ ] 同向不同谓词、反向关系、缺端点、未解析证据均有合成断言；没有明确反向关系时不生成反向边。
- [ ] 隐藏、删除、停用和部分获准证据先于展示、聚合与计数处理，空授权结果不泄露条目存在。
- [ ] 旧库无结构化材料时明确无覆盖；同一来源重复导入不生成重复节点或边。文字浏览、召回及普通导出仍通过对应回归。
- [ ] 对照表分别标明已证明的数据通路和尚未移植的图谱页面、在线学习写入或生命周期功能。写入测试名、结果和提交，状态转为待评审。

## 不做

不从私人数据库补数据，不覆盖正式快照，不对旧原件自动回填，不扩大网页或聊天会话权限，不调用真实模型。若上游端点没有足够的消歧信息，记录最小反例并明确缺少哪个字段，不凭猜测补图。
