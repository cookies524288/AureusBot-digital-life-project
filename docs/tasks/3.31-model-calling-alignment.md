## 目标和验收

模型调用像 MaiBot 一样稳定、低延迟：默认非流式、复用连接、失败重试一次，本地网关不绕路。

验收：

1. 普通对话默认使用非流式请求；需要流式的场景（如测速的首包观察）保留流式能力，但不再作为默认。
2. 所有服务商复用同一个带连接池的 HTTP 客户端（含远程）；本地回环继续直连、不走代理、不计客户端创建开销。
3. 超时、连接中断、5xx 等瞬时失败自动重试一次（同一模型、同一请求），重试计入预算与记账；4xx/认证/限流不重试。
4. 模型测试与普通调用共用同一套请求与解析；工具、视觉、思考等级、用量解析一致。
5. 失败原因沿用现有中文映射；不真实调用模型，测试用假客户端。

## 改动一览

- `aureus/organs/llm_adapter.py`：默认非流式、共享客户端（远程）、一次重试、解析统一。
- 测试：`tests/organs/test_llm_adapter.py`。

## 行为细则和边界情况

1. 非流式响应取 `choices[0].message.content`；推理内容仍不当正文（D127）。
2. 重试条件：超时、连接错误、5xx、空响应；不重试 400/401/403/404/422/429。
3. 共享客户端按事件循环与 `trust_env` 区分；本地 `trust_env=False`，远程沿用环境代理设置。
4. 重试只一次，第二次失败按原原因上报；用量记录两次尝试。
5. 不改服务商配置格式与密钥来源。
6. 不做：新增代理配置、改变模型选择顺序、改变预算。
