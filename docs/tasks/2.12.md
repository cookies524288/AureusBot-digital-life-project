## 后端接口（界面只能用这些）

网页接口在 `aureus/web/server.py` 注册，设置、时间线和配置接口分别在 `settings_api.py`、`timeline_api.py`、`config_api.py`；所有数据都要登录后从接口取，`/` 返回的页面本身不含任何数据。

| 接口 | 用途和返回 |
|---|---|
| `POST /api/login` `{password}` | 设置登录 cookie（HttpOnly、SameSite=Strict），返回 `{must_change_password}`。401 密码错，429 被限流（带 `Retry-After` 秒数） |
| `POST /api/logout` | 退出这台设备 |
| `GET /api/status` | `{must_change_password}`；没登录返回 401 |
| `POST /api/password` `{old_password, new_password}` | 改密码；成功后所有设备（包括这台）都退出，页面要回到登录 |
| `GET /api/history?limit=N` | 最新一批对话，每条 `{id, time, who, channel, content}`；`who` 是 `user`/`me`/`person`/`system` |
| `WS /ws` | 实时收发。发：`{"text": "..."}`。收：`{type, sender, content, channel, time?, id?}`，`type` 是 `reply`（它说的）或 `notice`（系统通知，不是它说的）；回复的 `id` 和 `time` 取自历史中的同一条记录，分段共享该记录；出错时 `{type:"error", detail}`，连接不断 |
| `GET /api/settings` | `{layers, locks, history}`：五层设定、三层锁、每层最近几个版本 `{id, source, time, content}` |
| `PUT /api/settings` | 只发要改的部分；改身份事实或不变人格时要带 `password`。返回 `{changed}`。403 密码不对，422 内容不合格 |
| `POST /api/settings/rollback` `{layer, version_id}` | 回退三层之一到最近的某个版本 |
| `GET /api/overview` | `{version, state_text, thinking, energy_level, energy_tier, current_task, restart_required}`；`version` 取自 `aureus.__version__`（D85） |
| `GET /api/timeline?hours=24&before_id=N&limit=100&types=message,diary_written` | `{records, next_before_id, context:{message_limit, boundary_id}}`；按序号升序，复用回复上下文查询，无 summary 字段；每条含 visibility 和原始 metadata |
| `GET /api/models` | `{exists, config, choices, key_status, key_entries, builtin_organs, warnings}`；补全默认值，密钥状态只有布尔值，key_entries 仅 id/name/kind（D87） |
| `PUT /api/models` `{config, password?}` | 整份提交，保留未改条目与注释；改已有服务商地址/密钥引用或新增带密钥的服务商需当前密码；返回 `{ok, restart_required, warnings}`，模型与器官后续调用热生效（D86） |
| `GET /api/keys` | `{vault, names, entries}`，vault 为 ok、none 或 unreadable，entries 仅 id/name/kind（D87） |
| `POST /api/keys` `{name, kind, value, password}` | 本机和当前密码确认，新建类型化密钥，同名拒绝覆盖；返回 `{ok, id, restart_required}`，不回显原文（D87） |
| `POST /api/keys/rename` `{id, name, password}` | 本机和当前密码确认，只改名称；稳定 id 不变（D87） |
| `PUT /api/keys` `{name, value, password}` | 只接受本机请求和当前密码，录入到密钥库；返回 `{ok, restart_required}`，不回显 value |
| `POST /api/keys/remove` `{id, password}`（兼容旧 name） | 只接受本机请求和当前密码；不存在返回 404；成功返回 `{ok, restart_required}`；网页密钥修改后续调用立即生效（D87） |
| `GET /api/config` | `{exists, config, schema, readonly, password_sections}`；读取文件中的值，可能尚未生效 |
| `PUT /api/config` `{changes, password?}` | 只提交要改的字段；safety、web 的真实改动需密码；返回 `{ok, changed, restart_required}`；未变化的字段忽略 |

除登录、退出、状态和改密码外，接口在默认密码 `admin` 没改之前都返回 403，WebSocket 握手直接拒绝。

登录限流默认按来源 IP 统计 300 秒内的失败次数：失败 7 次后锁定 30 秒（2026-11-21 用户调整）。重启清除当前锁定；已有密码文件时必须用已保存的密码，admin 仅在尚未设置密码时生效。忘记密码时，停止程序，把数据目录 `config/web_password.argon2` 移到同目录备份，重启后在本机用 admin 登录并设置新密码；不要直接覆盖旧文件。

新接口的错误 `detail` 都是中文字符串。配置先校验，再原子替换，模型/器官配置写入后热生效，运行配置与密钥录入重启生效（D86）；`restart_required` 只记录本进程成功的网页写入，进程重启清零。运行配置的 `config_version`、`web.enabled`、`web.allow_remote`、`web.port` 在网页只读。密钥接口按直接连接的来源地址判断本机，假设前面没有反向代理；局域网仍是明文 HTTP（D53）。模型配置整份提交期间的手动改动可能被覆盖；被修改的条目内注释会丢失，未修改条目保留。

## 必须保持的行为

1. **页面不含数据**：不在 HTML 里写死人设、名字或对话示例（有测试检查，例如 `tests/web/test_settings_api.py` 里断言页面不含示例名字）。
2. **默认密码时只能进改密码页**（D63 第 6 条）。登录返回 `must_change_password` 为真时，只显示改密码。
3. **每条对话标明通道**（D63 第 8 条）：历史和实时消息都显示 `channel`。
4. **系统通知和它说的话要分开显示**：`notice` 不是它说的（D35，不替它编回复），视觉上不能和 `reply` 一样。
5. **底线要再输一次密码**：改身份事实和不变人格时，页面要让用户输入当前密码放进 `password`；密码错会计入限流，429 时要提示等多久。
6. **回退不是删除**（D62、D81 第 8 条）：回退是再写一个新版本，历史还在。文案不要写成「删除」「撤销记录」。
7. **锁定开关三个一起发**：`locks` 三个开关都要写明，只能是 true/false（`LocksRequest` 是 strict 模式，漏写会被拒）。
8. **错误信息原样显示**：后端的 `detail` 已经是中文、不含密码，直接显示即可。
9. **不从外网加载资源**：不用 CDN 字体、脚本或样式。网页可能在没联网的局域网里用，外部资源还会把访问暴露给第三方。需要的库放进 `aureus/web/static/`，并按开发守则登记来源和许可证（THIRD_PARTY.md）。
10. **不引入构建工具链**，除非先回主会话定：现在页面是一个静态文件，随代码发布，没有 Node 依赖（D38 易安装）。
11. **手机能用**（03 号文档网页一节）。

### 验收意见

#### 第 1 轮修改说明（GPT，2026-11-21）

1. **运行报错和误退出的根因**：`require_session`、`require_ready` 原来是同步依赖，FastAPI 将其放进工作线程；多个请求及 WebSocket 会并发使用同一个会话数据库连接。旧实现中，三批各 100 个请求均复现 SQLite 异常与有效登录被错误返回 401，包括 `cannot commit - no transaction is active`。两处依赖改为异步函数，让检查留在原有事件循环；三处接口注册的依赖类型标注同步为 `Awaitable[str]`。不加锁、不加重试、不改变数据库或登录期限。
2. **错误密码的 401**：页面收到其他接口的 401 时，先用现有 `/api/status` 确认会话；只有状态接口也返回 401 才显示登录失效。旧密码错误保留原错误，状态查询断网也不冒充已确认的登录失效。
3. **退出与重连的时序**：重连的登录状态请求返回后，再检查是否仍想连接、是否仍已登录、是否已有连接，避免用户已经退出却又重连。

### 实现边界

- 默认器官指当前项目自带的 replyer、planner、judge、summarizer，界面始终提供；不能从网页删除，后端也拒绝移除已有默认器官。自定义器官可删除。
- 器官允许空模型列表；允许保留已删除模型的名字，以便明确提示失效引用。接口返回中文 warnings；空列表提示「xx未配置模型」，失效引用提示「xx引用了不存在的模型」。未知服务商、重复名字、非法参数与现有模型的思考等级冲突仍拒绝写入。
- 热重载先校验并构造新器官，再原子写文件，最后在事件循环里一次替换器官总线映射。正在进行的调用沿用原器官，之后调用使用新配置；保留同一个安全网关和账本，不重置预算、限流或会话。无可用模型时不发真实请求；同步更新探索、日记、人设回顾的器官可用标志。假器官模式继续使用假器官。
- 自动保存只提交完整合法的表单内容，串行发送，失败保留可见错误；敏感服务商变更仍需当前密码，不在浏览器持久保存密码。新增项先在弹窗中填写完整再添加；模型选择及已有项编辑不需要全页保存。
