# 3.21 滚动条鼠标靠近时自动变粗

状态：待实现
设计：维护者 2026-11-25 指令

## 目标

所有滚动条在鼠标靠近/进入可滚动区域时自动「吸附式」变粗一点，方便拖动；离开后恢复细胶囊。

## 行为与实现

1. 滚动条轨道固定约 12px 宽、透明；滑块平时显示约 6px 宽的胶囊（用透明边框 + `background-clip: content-box` 控制视觉宽度，不改变布局）。
2. 鼠标进入任意可滚动容器时（`*:hover::-webkit-scrollbar-thumb`），滑块视觉宽度增至约 10px；鼠标停在滑块上时再增至满宽约 12px 并加深颜色。
3. 离开后恢复；深浅主题都跟随变量。
4. Firefox：`scrollbar-width: thin` 无法做悬停变化，保持现状即可。
5. 只改全局滚动条 CSS，不改各组件布局；工作台内联后的滚动条同样适用。

## 验收

- 鼠标移入列表/消息区时滑块变粗，移出恢复；拖动更容易；页面布局不因滚动条变化而抖动；深浅主题正常。
