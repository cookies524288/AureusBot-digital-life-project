## 目标和验收

在 `c90059b` 用 Chrome 390 × 740 和 320 条合成资料打开文字记忆，切走再返回并让本次列表请求返回 503。加载中「下一页」禁用；失败后却重新显示旧 `第 1 / 64 页` 并启用「下一页」。「修正所选」已保持禁用。失败时应明确显示「读取失败」和「重试」，不得显示旧总页数、空结果或开放分页。

## 改动和边界

- 在 `createResourcePager` 的当前请求失败分支撤销已显示的总页数，并让分页按钮只在当前页的总页数已知且未读取中时启用。沿用现有错误消息、无全量页数的相似图片结果和迟到响应判断。
- 保留原重试目标和参数：普通列表重试失败的那一页，图谱和表达簇按原有约定清空页码并重试首页。成功后以新响应恢复分页。只更新列表与分页，不读或重写尚未提交的筛选草稿；新提交的筛选独立重载首页。
- 不新增配置、不改接口、版式或数据。不访问正式目录、实例或模型，不合并，不推送。

## 子步骤

1. 在 `tests/web/test_resource_browser.py` 用独立 Chrome 和回环模拟接口验证文字记忆、学习表情翻至中间页后返回失败，两个翻页按钮禁用、旧总页数不可见、筛选草稿保留，并可重试同一页。旧代码先失败。黑话和表达返回时原有的作用域重验会主动重新提交筛选，因此它们作为相邻既有专项，不套用保留中间页的场景。
2. 验证成功重试响应和已经切换的新筛选存在重叠时，旧响应不能覆盖新列表、页数或草稿；运行共享分页器的相邻专项。
