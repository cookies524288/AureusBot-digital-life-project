# 3.40 普通输入框与密钥输入框不弹浏览器密码自动填充

状态：待实现
设计：维护者 2026-11-26 指令

## 问题

浏览器的密码管理器在设置搜索框、密钥输入框等位置弹出「保存的密码 / 管理密码」浮层，挡住操作；只有网页登录密码需要自动填充。

## 目标

1. 只有登录页的密码输入框参与密码自动填充；其它所有输入框（搜索、设置、密钥、Prompt 等）都不触发密码管理器浮层。
2. 密钥输入框仍保持视觉遮挡（不显示明文），但不要被浏览器当作登录密码。

## 实现

1. 登录表单保留 `autocomplete="username"` / `autocomplete="current-password"`（按现有结构）。
2. 其它输入框统一加：`autocomplete="off"`（或 `new-password`）、`data-lpignore="true"`（LastPass）、`data-1p-ignore`（1Password）、`data-bwignore`（Bitwarden）、`data-form-type="other"`。
3. 密钥输入框若使用 `type="password"`，改为 `type="text"` 并用 CSS `-webkit-text-security: disc` 遮挡（或保留 password 但加上述属性；以实测不弹浮层为准）。
4. 不改输入校验与提交逻辑。

## 验收

- 设置搜索、密钥、Prompt、模型等输入框获得焦点时不再弹出密码管理器浮层；登录页密码仍可自动填充；密钥输入仍遮挡；深浅主题正常。
