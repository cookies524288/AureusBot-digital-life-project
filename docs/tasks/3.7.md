# 路线图 3.7 · 群聊行为对照

状态：待实现

先读 [目标部署与回复链](../13-references-and-migration.md)、D89、D90，以及 3.3–3.6a 的实际交付。使用合成数据、假时钟、假器官和模拟 QQ，保留能确定行为的输入与输出。

## 交付

1. 按目标部署已启用的规划、回复、召回、学习和插件逐项建立对照。列源文件及函数、版本、原行为、Aureus 入口、测试和差异。装在磁盘上不能证明正在使用；配置或调用证据不充分的项目列为待核实。先处理影响日常群聊的缺项。
2. 经正常收信入口回放同一组消息，覆盖点名、多说话人和引用、应当沉默、同词异义、私聊学到的内容在群中被提起、历史事件命中与无结果。捕获 Planner 实际得到的材料、它选择的动作或目标消息、Replyer 最终输入、投递对象及时间线。开启或关闭相关信号，用相同输入验证至少一项发言决定或时机受模拟意识状态驱动。
3. 将修订后的 Prompt 预览和最终调用对照。观察事件、器官的建议、子系统写入和真正的群消息分别有可核查的标识。继承项目的数据归属与人格锁。
