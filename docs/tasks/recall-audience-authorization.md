## 目标和验收

维护者澄清：群聊可召回私聊消息，包含在内部回复材料中看见原文；不等于可在群里公开原文。路线图 3.5、3.7 的召回链使用统一记忆，不因两次会话不同而拒绝合法候选；保留停用、移除、有效期以及独立限制。现有「只供参考，不要原样念出来」是提示词中的软约束，不是模型绝不泄露的保证。

联系人保密说明 `contact_notice` 与召回材料标题是两条独立软提示。对话根据目标感知是否为 `VERIFIED_USER` 决定是否附上联系人说明，不按记忆来源或可见标签决定。QQ 通道仅把已核实维护者的普通私聊升级为 `VERIFIED_USER`，群聊 B 保持 `VERIFIED_CONTACT`。联系人说明进入 Planner 和 Replyer 的 `system` 消息；召回标题和原文保留在 Replyer 的 `user` 材料里。两条提示都不保证输出保密。

## 改动一览
