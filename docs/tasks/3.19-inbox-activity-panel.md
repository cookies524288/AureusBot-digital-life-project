# 3.19 平台会话：去掉人工输入区，改成 Bot 活动可视化面板

状态：待实现
设计：D123（docs/10-decisions.md）

## 先读

- `aureus/web/static/index.html`：`#inbox-operations`（发送文字、上传文件表单）、`#inbox-thread`、`loadInboxOperations`、`clearInboxOperations`。
- `aureus/web/inbox_operations.py`：现有发送/上传接口（保留，不删）。
- `aureus/web/timeline_api.py`：`/api/timeline` 返回的 `round_id`、`metadata`、`reply_reference`、行动记录。
- `aureus/heartbeat/main_loop.py`：`_RoundTrace` 写入时间线的行动与回复参考事件。
- 隔离实例：数据根 `E:/Temp/aureus-ui-review`，端口 18770。

## 目标和验收

平台会话里不再提供人工代发消息/上传文件的入口；原位置改为像素风格的 Bot 活动面板，实时显示这一轮发生了什么。

验收：

1. 会话视图不再出现「发送 QQ 文字」「选择图片或 UTF-8 文本」「上传文件」等表单；后端发送/上传接口保留，planner 工具与现有调用不受影响。
2. 原位置显示活动面板，按轮次展示：收到消息 → 判断（可选）→ 规划（是否发言、理由、工具调用）→ 回复参考 → 投递；空闲时显示待机动画。
3. 面板只显示当前选中会话的事件；切换会话后清空并重新开始。
4. 像素风格：使用项目已有的像素字体（ArkPixel）、方块边框、点阵/闪烁光标，配色跟随深浅主题。
5. 面板只读，不提供任何操作按钮；不显示私聊原文之外的本应隐藏的内部字段（工具参数只显示工具名与简短结果）。

## 改动一览

- `aureus/web/static/index.html`：删除 `#inbox-operations` 表单与相关脚本；新增活动面板容器、轮询与渲染。
- `aureus/web/timeline_api.py`：`/api/timeline` 增加可选 `conversation` 过滤（平台 + 账号 + 类型 + 对方），只返回该会话的记录；不传时行为不变。
- 样式：面板使用现有 CSS 变量与像素字体；必要时补少量样式。

## 行为细则和边界情况

1. 轮询：会话视图可见且页面在前台时，每 1.5 秒请求一次 `/api/timeline?hours=1&limit=60&conversation=…`；切页或页面隐藏时停止。失败静默重试，不弹 toast。
2. 过滤：按 `round_id` 归组，取最新一轮；`planner` 行动、`reply_reference`、`judge`、`reply_delivered` 等事件映射为固定步骤。缺失步骤显示为「跳过」而不是空白。
3. 隐私：工具参数只显示工具名与是否成功；不显示模型内部推理原文以外的敏感字段；私聊材料仍按现有可见性规则。
4. 发送接口保留但前端不再调用；若后续确认没有其它调用方，再单独决定是否删除。
5. 不做：新增 planner 工具、改变发送规则、改变收件箱权限。
