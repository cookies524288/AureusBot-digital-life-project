# 3.42 「返回平台桌面」改成像素风返回图标

状态：待实现
设计：维护者 2026-11-26 指令

## 目标

把平台会话右上角的文字按钮「返回平台桌面」换成一个像素风格的返回图标，点击行为不变。

## 实现

1. `aureus/web/static/index.html`：按钮内容改为像素风返回图标（沿用项目 ArkPixel/像素图标体系；没有现成图标时用内联 SVG 像素箭头）。
2. 保留 `aria-label="返回平台桌面"`、`title` 与现有点击处理；悬停有提示。
3. 尺寸与「刷新」按钮协调；窄屏不溢出。

## 验收

- 按钮显示为像素风返回图标；点击回到平台桌面；悬停提示与键盘可访问；深浅主题与窄屏正常。
