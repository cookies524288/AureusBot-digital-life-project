# 3.42 「返回平台桌面」改成像素风返回图标

状态：完成
设计：维护者 2026-11-26 指令

## 目标

把平台会话右上角的文字按钮「返回平台桌面」换成一个像素风格的返回图标，点击行为不变。

## 实现

1. `aureus/web/static/index.html`：按钮内容改为像素风返回图标（沿用项目 ArkPixel/像素图标体系；没有现成图标时用内联 SVG 像素箭头）。
2. 保留 `aria-label="返回平台桌面"`、`title` 与现有点击处理；悬停有提示。
3. 尺寸与「刷新」按钮协调；窄屏不溢出。

## 验收

- 按钮显示为像素风返回图标；点击回到平台桌面；悬停提示与键盘可访问；深浅主题与窄屏正常。

## 实现记录（2026-11-26）

- `aureus/web/static/index.html`：SVG sprite 新增 `i-back`，复用 `i-up` 旋转 -90°（与现有 `i-down` 复用 `i-up` 的写法一致），16×16、`fill:currentColor`、`shape-rendering:crispEdges`，沿用现有像素图标体系。
- `#inbox-home` 去掉文字，改为 `<svg class="ico" aria-hidden="true"><use href="#i-back"/></svg>`；保留 `id`、`btn small hidden` 和原有点击监听，新增 `aria-label="返回平台桌面"` 与 `title="返回平台桌面"`。
- 新增 `#inbox-home.btn{width:31px;height:31px;padding:0}`：图标按钮做成方形；「刷新」按钮实测高 30.8px，方形按钮 31px，垂直中心相差 0.008px；窄屏只占 31px 宽。
- 取舍：图标由 `i-up` 旋转得到，不新画一套箭头；31px 是为了和「刷新」按钮的现有行高对齐，若以后刷新按钮字号或内边距变化需要一起调整。
- 只改了 `index.html`；没有改后端、`frontend/`、`aureus/organs/`。
- 提交：`436b52a`（只含 `aureus/web/static/index.html`）。
