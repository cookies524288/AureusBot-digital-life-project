2. **平台桌面整理**：
   - 去掉软件图标外侧的卡片框（`#inbox-platforms` 里 `.card` 的边框/背景），图标本身保留。
   - 删除图标下方的「配置」按钮 `#inbox-config-qq` 及其监听；保留右键图标打开配置（`#inbox-open-qq` 的 `contextmenu`），并在图标上增加 `title`/`aria-description` 提示「右键配置」。
   - 已完成（`91286a9`）：QQ 与「未归类历史」两个图块都去掉 `card` 外框；配置按钮与监听已删；右键、菜单键、Shift+F10 仍可进入配置（已实测 `#config`）；桌面提示改为「点击图标进入会话；右键图标打开平台设置」，QQ 未启用提示同步改写。截图 `E:/Temp/ui-shots/batch1-2-platform-desktop.jpg`。
3. **消息顺序**：平台会话窗口与时间线页面都改为**旧消息在上、新消息在下**（聊天式），进入时自动滚到底部；分页/加载更早时保持当前滚动位置不跳。
   - 已完成（`b6981b1`）：时间线去掉渲染前的倒序，按 id 升序显示，历史带在前、当前上下文带在后，分隔线箭头文案同步；进入、刷新、切换筛选后滚到底部；「加载更早的」按钮从列表下方移到列表上方。平台会话原本就是旧在上、新在下（接口新在前，前端逐页反转），补上进入/翻页后把最新一条滚入视野。截图 `E:/Temp/ui-shots/batch1-3-timeline-entry-bottom.jpg`、`batch1-3-timeline-top-oldest.jpg`。
4. **会话气泡**：平台会话的消息改用私聊页同款气泡结构（`article.msg` 及左右方向样式），头像保留但缩小到与私聊一致；时间、发送者信息放气泡上方一行。
   - 已完成（`e8240f1`）：来信 `msg person`、去信 `msg user`，复用 `.bubble` 内边距、圆角和配色；头像从 32px 缩到 28px；meta 行在气泡上方，引用/戳一戳按钮保留。隔离实例没有真实 QQ 会话，气泡用控制台注入的合成消息检查，未改任何数据。截图 `E:/Temp/ui-shots/batch1-4-inbox-bubbles-synthetic.jpg`。

### 批次 2：会话窗口

5. **固定窗口与滚动加载**：平台会话消息区改为固定高度（可用 `min(60dvh, …)` 或 flex 布局填满可用高度）、内部滚动；删除 `#inbox-pagination` 一组翻页控件及 `inbox.page/lastPage` 相关逻辑。
   - 用 `/api/inbox/messages?before_id=…&limit=…` 游标向前加载更早消息；滚到接近顶部时自动加载。
   - 进入会话时预取 2 页（约 2×50 条），首屏直接渲染；加载中显示轻量状态，失败可重试。
   - 去重按消息 id；保持现有的权限、撤权与已读水位语义。
   - 已完成（`c7f4425`）：右栏改为 flex 列，消息区 `flex:1` 填满剩余高度并在内部滚动；翻页控件与 `inbox.page/lastPage` 已删。进入会话先取最新 50 条、再取前一页，两页一起渲染并停在最新处；滚到距顶部 120px 内自动用 `before_id` 加载，跨到旧时间线时带 `before_source=timeline`。加载中显示「正在加载更早的消息…」，失败显示原因和「重试」，失败后不自动重复请求。加载更早时用滚动高度差补回位置（实测锚点位移 0–1px）；去重键用 `source:id`，因为收件箱原件与旧时间线是两套编号，单看 id 会撞号。布局用 flex 填满可用高度（未用 `min(60dvh)`）：1280×900 下消息区 693px、页面无整页滚动；390×700 下消息区 247px、页面无溢出。隔离实例没有真实 QQ 会话，用浏览器注入的合成消息和假接口验证了预取 2 次请求、自动加载、失败重试、重复 id 只渲染一次、120 条消息滚到底部；真实接口用未授权会话验证游标参数返回 200 空列表。截图 `E:/Temp/ui-shots/batch2-1-inbox-fixed-height.jpg`、`batch2-2-inbox-loading-older.jpg`、`batch2-3-inbox-retry.jpg`、`batch2-4-inbox-mobile.jpg`。
