## 目标和验收

长期记忆页的布局与操作对齐 MaiBot 知识库，保留 Aureus 的圆角视觉；只做全局范围；**记忆检修、记忆移除不改造**（保留现状，不删除入口，不做样式重做）。

验收：

1. 主标签：记忆查询、图片记忆、记忆流、导入导出（沿用现有命名）；记忆检修、记忆移除保持现状，不纳入本次重排。
2. 记忆查询内分「文字记录 / 人物画像」两个子标签，各有搜索框、筛选和列表。
3. 文字记录：搜索（内容、名称、关系、事实、情节或 ID）、类型筛选、「显示停用」开关、查询按钮；右上显示统计（段落/关系/事实/情景记忆等现有计数）；列表为卡片：勾选、类型徽标、标题、摘要、来源标签；支持批量「修正所选」。
4. 详情抽屉：类型与来源、时间、全文、来源、关联条目；操作「图谱 / 修正 / 删除」（图谱入口按现有关系图能力，删除按现有移除接口）。
5. 人物画像：按名称/群名片/person_id 搜索；列表显示画像徽标、名字、版本、更新时间；详情抽屉显示人物 ID、称呼、别名、过期时间，以及身份设定、关系设定、稳定了解、相处偏好、近期互动、不确定信息等分节。
6. 全局范围：不显示聊天范围筛选，接口始终按全局范围调用。
7. 圆角与配色沿用 Aureus；窄屏下详情抽屉改为全宽或底部抽屉。

1. 现有功能不丢：搜索、筛选、分页、勾选、批量修正、详情、图谱入口、删除确认、导入导出流程保持可用。
2. 详情抽屉用现有数据字段；缺字段时留空或写「暂无」，不新造后端字段；确实需要时写进「待设计问题」。
3. 记忆检修、记忆移除的现有入口和逻辑不动；如果重排导致它们与新标签结构冲突，优先保持原样并记录。
4. 空状态写明下一步；加载失败显示原因与重试。
5. 不做：修改召回、修改记忆数据、改变权限与撤权语义。

## 待设计问题

1. 人物画像接口没有结构化的「身份设定 / 关系设定 / 稳定了解 / 相处偏好 / 近期互动 / 不确定信息」字段。当前从画像记录的 name、nickname、group_cardname、account、relationship_state、memory_points、impression 和 original 里的近期互动、不确定信息等尽力展示，缺失写「暂无」。若要求这些分节总有内容，需要后端返回结构化字段或约定 `profile_text` 的解析格式，不能由前端新造。
2. 文字记录没有独立标题字段，卡片标题暂用人物名（没有时用类型），摘要是正文。如果希望标题取首句或摘要，需要后端提供标题字段或确认前端截取规则。
3. 关系类型不支持正文修正（现有检修接口会拒绝 `correct`），因此关系详情只提供「图谱 / 删除」及冻结、保护等检修操作；如果要求关系也能「修正」，需要新增后端能力。
4. 记忆流移除了「聊天流」筛选以符合全局范围要求；如果以后仍需要按聊天流查看，需要另行设计成只读分组或详情，而不是筛选。
