# 3.30 模型超时改为 90 秒，模型测试不再因连续失败停用

状态：待实现
设计：D132（docs/10-decisions.md）

## 先读

- `aureus/organs/model_config.py`：`DEFAULT_TIMEOUT_SECONDS`。
- `aureus/safety/runaway_guard.py`：`blocked_reason`、`admit`、`report`。
- `aureus/safety/gateway.py`：`_admit`、`_finish`。
- 测试：`tests/safety/test_runaway_guard.py`（如存在）、`tests/safety/test_gateway.py`。

## 目标和验收

1. 服务商默认超时从 60 秒改为 90 秒；显式配置的超时继续生效。
2. 模型测试（`model_test`）不再因为连续失败被暂停；每分钟频率限制仍然生效。
3. 其它器官的失控拦截行为不变。
4. 失败原因、用量记账与预算语义不变。

## 改动一览

- `aureus/organs/model_config.py`：默认超时 90。
- `aureus/safety/runaway_guard.py`：失败暂停豁免集合（`model_test`），频率限制照常。
- 测试：默认值与豁免行为。

## 行为细则和边界情况

1. 豁免只针对「连续失败暂停」，不针对「每分钟调用次数上限」。
2. `report` 对豁免器官不计连续失败；成功/失败都不影响其它器官。
3. 不新增配置项；豁免集合是模块常量并注明 D132。
4. 不做：改变重试、改变失败原因、放宽预算。
