# 3.36 模型配置页按 MaiBot 布局重做

状态：待实现
设计：维护者 2026-11-26 指令与五张 MaiBot 模型页截图；布局同款、视觉保留 Aureus 圆角风格

## 目标

模型配置页的信息结构、布局和操作逻辑与 MaiBot 的模型管理页一致，控件使用 Aureus 现有圆角与配色；后端配置格式与现有接口不变。

## 布局（参考截图）

1. **左侧厂商栏**：标题「模型厂商」，右上「+」添加厂商；第一项「全部」带数量；每个厂商显示名称、`base_url`、该厂商模型数；选中项高亮。
2. **右侧主区**：顶部搜索框（模型名称、标识符或提供商）；右上「添加」模型。
3. **模型表格**：列为「使用（启用勾选）」「模型名称」「模型标识符」「提供商」「视觉」「默认输入价」「默认输出价」「操作（测速 / 编辑 / 删除）」；价格按 ¥/M token 显示；启用状态用勾选框。
4. **编辑模型弹窗**：
   - 模型名称、API 提供商（下拉）；
   - 模型标识符：可下拉选择该厂商可用模型（带搜索与刷新按钮），也可手填；
   - 启用视觉（勾选）；
   - 默认价格：输入 / 输出 / 缓存（¥/M token）；
   - 分时价格：可添加时段（每日、服务器本地时间、价格）；
   - 启用思考（写入 `thinking.type`）+ 思考力度（低/中/高）；
   - 启用联网搜索（仅支持的协议）；
   - 自定义模型温度、自定义最大 Token（各带开关）；
   - 额外参数：显示已配置参数数量；提供「可视化编辑」（键/值/类型，支持嵌套对象与数组）和「JSON 编辑」（实时校验与预览）两种模式；
   - 底部「取消 / 保存」。
5. **添加/编辑厂商**：名称、协议、`base_url`、密钥来源，沿用现有配置字段。

## 行为与边界

1. 后端仍使用 `models.toml` 的 providers/models 结构与现有 API；不改配置格式、密钥来源与器官绑定。
2. 启用/停用、测速、删除都要落到现有接口；删除需确认；测速沿用现有模型测试。
3. 搜索与厂商筛选只影响列表展示；数量统计随筛选更新。
4. 保存后刷新列表并保留当前筛选与选中厂商；失败显示原因。
5. 窄屏：厂商栏折叠为顶部下拉或横向列表；表格改卡片；弹窗全宽。
6. 保留现有全部功能（密钥管理、器官绑定、模型目录等入口不丢）。
