- 测试：`tests/people/test_directory.py`（如存在）。

## 目标和验收

1. 新建联系人必须有名字：优先显示名，没有时用账号作为临时称呼（如「QQ 12345」）；之后收到真实显示名时替换临时称呼。不再新建空名字档案。
2. 已有的空名字档案不改数据，前端显示账号，不再出现「未命名人物」。
3. 记忆卡片、详情与记忆流不显示 `statement:<哈希>:`、`paragraph:<哈希>:` 等来源序号前缀；原始正文在库中不变，修正与检索不受影响。
4. 深浅主题、窄屏正常；记忆页其它功能不变。

## 改动一览

- `aureus/people/directory.py`：`meet`/`_meet_id` 接受显示名；临时称呼与替换规则。
- `aureus/heartbeat/main_loop.py`：调用时传 `perception.sender_name`。
- `aureus/web/static/resource-management.js`：人物名兜底为账号；记忆正文前缀清理。
- 测试：联系人命名规则。

## 行为细则和边界情况

1. 临时称呼格式：平台名 + 账号，如「QQ 12345」；平台未知时只用账号。
2. 只有当前名字是空或临时称呼时才用新显示名替换；用户或资料包设置过的名字不覆盖。
3. 前缀清理只针对正文开头、形如 `statement:`/`paragraph:` + 32 位以上十六进制 + `:` 的模式；正文中间的同样文本不动。
4. 清理只用于展示；批量修正提交时仍提交用户看到的正文（去掉前缀后的文本），由用户确认。
5. 不做：迁移旧档案、改变记忆存储、改变召回。
