# 3.47 输入中气泡改成 Bot 自己的空气泡，完成后变成发出的消息

状态：待评审
设计：维护者 2026-11-26 指令

## 目标

Bot 正在输入时，在消息列表末尾显示一个**Bot 自己发出的**气泡（与已发出的回复同款：右侧、金色、同样的圆角与字号），气泡内显示打字动画。回复完成后，这个气泡原地变成真正发出的文字，不闪烁、不跳动。

## 实现

1. `aureus/web/static/index.html`：把现在左侧的「输入中」气泡改成右侧的 Bot 发送方向气泡，内容为三点打字动画。
2. 气泡放在 `#inbox-messages` 列表末尾（不是列表外的独立区域），跟随滚动。
3. 新回复到达（轮询或 3.43 的推送）时：若列表末尾是输入中气泡且新消息来自 Bot，用真实消息替换该气泡；多段回复时第一段替换气泡、后续段追加。
4. 回复被取消、失败或切换会话时移除气泡。
5. 减少动态偏好时显示静态「输入中」文字；深浅主题与窄屏正常。
6. 不改后端接口与打字状态来源。

## 验收

- 输入中气泡在右侧、与 Bot 回复同款；回复到达后同一位置变成文字，无闪烁或布局跳动；取消/失败/切会话时消失；多段回复正常；窄屏与主题正常。

## 前端实测（2026-11-26）

实现：`typingIndicator(false)` 改成 `msg inbox-msg user inbox-typing`，与 Bot 已发出的回复
共用 `.msg.user .bubble` 的金色气泡和右下角小圆角，头像用 `inboxAvatarPlaceholder()`；
气泡追加到 `#inbox-messages` 末尾，不再用列表外的 `#inbox-typing`。`appendInboxMessages`
遇到第一条 `direction='outgoing'` 的新消息时原地替换气泡，后续消息追加；替换后把
`typingSession.bubbleReplaced` 置为真，避免下一轮轮询把气泡再插回来。输入结束（active
转 false）时移除气泡并补拉一次最新消息；失败、取消、切会话同样移除。

- 样式与方向：气泡是列表最后一个子元素，计算 `align-self: flow-end`（等价 flex-end），
  右边缘距消息区 12px；气泡背景 `rgb(181, 137, 0)` 与 Bot 回复气泡完全一致；三点动画
  存在。截图 `E:/Temp/ui-shots/343-06-typing-bubble.png`。
- 原地变文字：追加一条 Bot 消息后 `.inbox-typing` 消失，末尾气泡文本为「这是 Bot 的回复」，
  `typingSession.bubbleReplaced=true`；截图 `343-07-reply-replaced.png`。
- 取消/失败/多段：`clearTyping()` 后气泡消失；把 typing 接口改成 500 后约 1 秒气泡消失；
  连续两段 Bot 回复后两段都在、无气泡；typing 变 false 后气泡消失。
- 主题与窄屏：深色截图 `343-08-inbox-dark.png`，390×700 截图
  `343-09-inbox-narrow.png`；减少动态偏好沿用 CSS 的静态「输入中」文字。
- 环境偏差：假器官实例没有真实 QQ 输入中状态，用伪造会话和假 typing 接口验证；原 18770
  和正式 28976 未改动。Console `exceptions=[]`、`errors=[]`；按维护者要求未跑 pytest。
