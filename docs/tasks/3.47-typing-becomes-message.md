# 3.47 输入中气泡改成 Bot 自己的空气泡，完成后变成发出的消息

状态：待实现
设计：维护者 2026-11-26 指令

## 目标

Bot 正在输入时，在消息列表末尾显示一个**Bot 自己发出的**气泡（与已发出的回复同款：右侧、金色、同样的圆角与字号），气泡内显示打字动画。回复完成后，这个气泡原地变成真正发出的文字，不闪烁、不跳动。

## 实现

1. `aureus/web/static/index.html`：把现在左侧的「输入中」气泡改成右侧的 Bot 发送方向气泡，内容为三点打字动画。
2. 气泡放在 `#inbox-messages` 列表末尾（不是列表外的独立区域），跟随滚动。
3. 新回复到达（轮询或 3.43 的推送）时：若列表末尾是输入中气泡且新消息来自 Bot，用真实消息替换该气泡；多段回复时第一段替换气泡、后续段追加。
4. 回复被取消、失败或切换会话时移除气泡。
5. 减少动态偏好时显示静态「输入中」文字；深浅主题与窄屏正常。
6. 不改后端接口与打字状态来源。

## 验收

- 输入中气泡在右侧、与 Bot 回复同款；回复到达后同一位置变成文字，无闪烁或布局跳动；取消/失败/切会话时消失；多段回复正常；窄屏与主题正常。
