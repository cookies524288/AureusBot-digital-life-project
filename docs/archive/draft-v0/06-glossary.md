# 06 · 术语表

> 本项目内部术语的精确定义。避免歧义。

---

## 核心概念

### 功能性自我（Functional Self）

一个持续存在、可读写、参与决策的系统状态。
它不需要主观体验，只需要在功能上具备：

```text
自我/环境区分
能动感
元认知
叙事连续性
能力边界
```

**不声称**现象学意识。

### 自我模型（MirrorSelf）

功能性自我的结构化表示。

```text
不可变层：名字、价值观、边界、身份不变量
可变层：目标、注意力、置信度、关系、叙事位置
```

### 全局工作空间（MindDome）

容量有限的"当前意识内容"。

```text
候选 → 显著性竞争 → Top-K → 广播给器官
```

不在工作空间内的内容仍可被后台处理，但不参与当前决策。

### 器官（Organ）

一种 LLM 驱动的认知功能。

```text
无状态或短时状态
有输入输出契约
有置信度
有失败边界
不能修改核心身份
```

器官不是 Agent，不自主决策。

### 器官总线（OrganBus）

器官的注册、调度、超时、降级。

### 内感受（Interoception / Soma）

系统级的"身体状态"。

```text
能量、负荷、疲劳、压力、社交需求、唤醒度、效价
```

### 显著性（Salience）

决定内容是否进入工作空间的评分。

### 认知帧（CognitiveFrame）

每轮组装、广播给所有器官的完整上下文。

**器官唯一的输入。**

### 意图（Intent）

Executive 选定的行动。

```text
目标 + 动作 + 参数 + 预期 + 置信度 + 归因
```

### 预期（Expectation）

行动前记录的预测结果。

### 结果（Outcome）

行动后采集的真实结果。

### 预测误差（PredictionError）

预期与结果的差异。

驱动自我模型、世界模型、情绪、技能的更新。

### 闭环（Prediction Loop）

```text
预测 → 行动 → 结果 → 误差 → 更新
```

没有闭环的行动视为未完成。

### 记忆（Hippo）

长期记忆系统。

```text
情景 / 语义 / 关系 / 技能 / 叙事
```

### 叙事（Thread）

长期自我叙事。

不是聊天记录，而是"我成为谁"的时间线。

### 治理（Warden）

横切所有层的安全与审计。

```text
身份不变量保护
权限
审批
审计
回滚
熔断
```

### 效应器（Effector）

把 Intent 变成真实动作。

### 适配器（Adapter）

把外部事件归一化为 Percept。

## 状态术语

### 不可变层（Immutable）

自我模型中永不被程序改写部分。

只能由人类或配置文件初始化。

### 可变层（Mutable）

自我模型中可被更新的部分。

写入必须带 reason，必须审计。

### 熔断（Circuit Breaker）

连续失败后暂停某个器官或动作。

### 降级（Degradation）

器官失败时返回保守结果，而不是报错。

### 回滚（Rollback）

恢复到之前的快照。

### 审计（Audit）

记录所有关键写入与动作，不可删除。

---

## 时间尺度

### 快速环

毫秒到秒。感知、GUI、游戏。

### 对话环

一轮到几轮。说话、反馈。

### 昼夜环

小时到天。巩固、消化、叙事。

### 发展环

周到月。技能、关系、认同。

---

## 评估术语

### 身份一致性

跨会话、跨模型、跨重启后自我描述的一致程度。

### 记忆连续性

关键经历在后续对话中被正确引用。

### 自我/他人区分

能正确区分"我说的"与"别人说的"。

### 行动归因准确率

能正确回答"这件事是不是我做的"。

### 置信度校准

声称的置信度与实际正确率的偏差。

### 消融实验（Ablation）

去掉某个模块，观察行为是否退化。

如果没退化，该模块是装饰品。

---

## 明确避免的词

```text
"意识"        → 改用"功能性自我"
"灵魂"        → 改用"自我模型"
"真正的生命"  → 改用"持续运行的功能性主体"
"觉醒"        → 改用"状态更新"
```

对外表述统一、克制、可验证。
