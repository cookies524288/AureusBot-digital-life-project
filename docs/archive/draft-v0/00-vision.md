# 00 · 愿景与目标

> 本文回答三个问题：**要做什么、不做什么、怎么判断做成了。**

---

## 1. 一句话

**Aureus 是一个功能性自我运行时：它让一个持续的自我模型作为系统状态存在，让 LLM 作为可替换的认知器官参与思考，而不是让 LLM 扮演一个角色。**

---

## 2. 问题陈述

当前几乎所有"数字生命""AI 伴侣"的实现，本质都是同一种结构：

```text
System Prompt（你是谁）
+ 上下文（你看到什么）
+ 记忆检索（你想起了什么）
+ 工具（你能做什么）
→ LLM 生成一段文本
→ 系统把它当作"它说的话"
```

这个结构有一个根本问题：

> **"自我"是每次生成时临时构造出来的产物，而不是持续存在的实体。**

具体表现：

| 现象 | 根因 |
|---|---|
| 人格漂移 | 身份由提示词承载，提示词一变、上下文一变，人就变了 |
| 记忆断裂 | 记忆是外部检索，触发依赖模型主动查询 |
| 无能动感 | 行动由模型一次性决定，没有意图→行动→归因的链路 |
| 无元认知 | 不知道自己不知道，不知道自己在被情绪影响 |
| 无真实注意 | 所有上下文平铺，没有容量有限的竞争与广播 |
| 无闭环 | 结果不回流为预测误差，系统不因结果而改变 |

这些不是"提示词写得不够好"，而是**架构层面的缺失**。

---

## 3. 目标

### 3.1 必须实现（MUST）

```text
M1  结构化自我模型
    一个持续存在、可读写、带不可变层的 Self-State，
    而不是一段被反复塞进提示词的文字。

M2  容量有限的全局工作空间
    每轮只有少数内容进入"当前意识"，
    其余留在后台，通过显著性竞争决定是否广播。

M3  LLM 器官化
    语言、规划、记忆、批评、社会认知等能力以器官形式接入，
    每个器官有输入输出契约、置信度、失败边界，
    且不能修改核心身份。

M4  预测误差闭环
    每次行动前记录预测，行动后比对结果，
    误差回流到自我模型、世界模型、情绪与技能。

M5  身份连续性
    重启、换模型、换前端、换通道后，
    仍然是同一个自我，叙事不断裂。

M6  可观测
    自我状态、工作空间内容、器官调用、误差、情绪
    全部可查询、可审计、可回放。
```

### 3.2 应该实现（SHOULD）

```text
S1  内感受与情绪
    能量、压力、疲劳、社交信号等作为系统状态参与决策，
    而不是仅作为提示词里的一句话。

S2  元认知
    置信度校准、错误检测、能力边界感知、
    "我知道自己不知道"。

S3  自我/环境/所有权
    区分"这是我做的"与"这是外部发生的"，
    行动有意图、有归因。

S4  叙事自我
    长期时间线上的自我叙事，
    不是逐条聊天记录，而是"我经历了什么、我成为了谁"。

S5  治理与安全
    身份不变量、权限边界、危险动作审批、可回滚。
```

### 3.3 明确不做（WON'T）

```text
W1  不宣称现象学意识
    对外统一表述：Aureus 实现功能性自我模型，
    不声称主观体验，不回答"里面是否亮着灯"。

W2  不做"更大的人设提示词"
    身份必须落在结构化状态里，不能靠提示词堆砌。

W3  不让 LLM 直接改写核心身份
    身份不变量、价值观、安全边界属于不可变层。

W4  不做无监督的自我重写
    自我改进必须经过：生成 → 测试 → 审查 → 灰度 → 回滚。

W5  不绑定单一模型厂商
    器官可替换，模型可替换，架构不依赖某一家 API。
```

## 4. 设计原则

### P1 身份是状态，不是文本

自我模型是结构化数据，有 schema、有版本、有不可变层。
LLM 读取它，但不能任意覆写。

### P2 意识是瓶颈，不是全集

不把所有信息塞给模型。
全局工作空间容量有限，进入需要竞争，进入后广播。

### P3 器官无状态，Core 有状态

器官是短时、可替换、可并行的认知功能。
状态归 Core 所有。

### P4 一切行动都要闭环

没有预测的行动不允许执行；
没有结果回流的行动视为未完成。

### P5 可观测优先于聪明

宁可系统笨一点，也要每一步都能看见、能解释、能回放。

### P6 失败要朝安全方向倒

不确定时选择更保守的行为；
异常时拒绝而不是放行。

---

## 5. 与现有方案的关系

Aureus 不试图取代聊天机器人框架，而是**为它们提供自我层**。

```text
聊天身体（QQ / IM / 前端）
        ↓  感知事件、行动请求
Aureus Core（自我、工作空间、器官、闭环）
        ↓  认知帧、意图、行动
记忆系统（长期记忆、叙事）
```

Aureus 可以独立运行，也可以作为"内核"接入已有的身体。

## 6. 成功标准

不用"像不像人"评估，用可测指标。

### 6.1 功能性指标

| 指标 | 定义 | 目标 |
|---|---|---|
| 身份一致性 | 跨会话、跨模型、跨重启后，自我描述与价值观的一致程度 | 高 |
| 记忆连续性 | 关键经历在后续对话中被正确引用 | 高 |
| 自我/他人区分 | 能正确区分"我说的"与"别人说的" | 高 |
| 行动归因准确率 | 能正确回答"这件事是不是我做的" | 高 |
| 置信度校准 | 声称的置信度与实际正确率的偏差 | 低 |
| 目标稳定性 | 长期目标在干扰下是否漂移 | 低漂移 |
| 中断恢复 | 被打断后能否恢复到原任务 | 高 |
| 边界遵守率 | 安全边界被违反的比例 | 接近 0 |
| 叙事连贯性 | 长期叙事是否自洽 | 高 |

### 6.2 消融实验

必须能回答：

```text
去掉 Self-Model      → 行为是否退化为普通 chatbot？
去掉 Global Workspace → 是否退化为上下文堆叠？
去掉闭环反馈          → 人格是否漂移？
去掉器官契约          → 是否出现越权与幻觉？
```

如果消融后没有明显差异，说明该模块是装饰品。

---

## 7. 非目标

```text
不是通用 Agent 框架
不是工作流编排引擎
不是模型路由中间件
不是聊天机器人产品
```

这些能力可以有，但不是立项理由。

---

## 8. 风险与边界

| 风险 | 应对 |
|---|---|
| 架构过度复杂，无法落地 | MVP 严格限定四层闭环，其余延后 |
| 自我模型被 LLM 污染 | 不可变层 + 写入审计 + 回滚 |
| 情绪/执念正反馈失控 | 限幅、衰减、上限、熔断 |
| 闭环导致行为僵化 | 保留探索噪声与随机性 |
| 评估主观化 | 只用可测指标与消融实验 |
| 被误解为"有意识" | 对外表述统一、文档明确边界 |

---

## 9. 一句话总结

> **Aureus 要证明的不是"AI 有意识"，而是"自我可以是一个持续运行的系统状态，而 LLM 只是它的一部分"。**
